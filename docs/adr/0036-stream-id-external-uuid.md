# Идентификатор потока — UUID источника как есть: `version: :external`

Если неизменяемый естественный ключ event-sourced агрегата — сам UUID внешнего источника,
уникальный на все виды агрегатов, которые из этого источника грузятся, id потока MAY быть этим
UUID без UUIDv5. Prim такого id объявляется `use Core.Prim.UUID, version: :external`: `new/0` и
`from_key/1` не генерируются, версия на разборе не проверяется. Дополняет ADR-0017, не пересматривая
его: для ключа, который UUID не является, правило прежнее. Норма — `docs/rules/app/13-repos.md`,
«Уникальность без индекса состояния».

## Контекст

Факты на 2026-10-01:

- `app/13` требует id потока — UUIDv5 от естественного ключа (ADR-0017);
- у потребителя A шесть агрегатов — справочники и документы внешней системы, чей ключ уже
  глобально уникальный UUID; потребитель берёт его как есть и объявляет Prim
  `version: 1, check_version: false`;
- такое объявление генерирует `new/0`: `Agg.ID.new()` выпускает id в обход источника — ровно
  «плохо» нормы, — и компилятор этого не видит;
- `version:` у `Core.Prim.UUID` уже значит «откуда id»: 1 / 4 / 7 — генерация, 5 — из ключа без
  `new/0`.

## Рассмотренные варианты

- **UUIDv5 от UUID источника.** Отвергнут: второй идентификатор того же объекта — в логах, запросах к
  источнику и сверках приходится держать оба и переводить один в другой.
- **MAY без правки библиотеки.** Отвергнут: исключение тянет лазейку `new/0`.
- **Ортогональная опция `generate: false`.** Отвергнут: даёт бессмысленные сочетания
  (`version: 5, generate: false`, `generate: false` без `check_version: false`), которые пришлось бы
  запрещать.
- **`version: :external` (принято).** Продолжает смысл `version:` и не плодит запрещённых сочетаний.

## Решение

- `version: :external`: `new/0` и `from_key/1` нет; разбор принимает UUID любой версии;
  `check_version:`, `namespace:`, `scope:` при нём запрещены на сборке.
- MAY в `app/13`: ключ — UUID источника, уникальный на все виды, которые из источника грузятся →
  id потока равен ему, Prim — `version: :external`.

## Цена

- **Уникальность — на совести источника:** коллизия UUID между видами одного источника склеит
  потоки; условие нормы — «уникален на все виды».
- **Смена источника** (другой UUID того же объекта) переименовывает поток — как и смена ключа при
  UUIDv5.
