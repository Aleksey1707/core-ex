# Пакетная команда с пустым пакетом — исход `:unchanged`, HTTP 204

Пакетная команда event-sourced агрегата (вход — список изменений), получившая пустой пакет,
отдаёт `{:ok, :unchanged}`: записи нет, ждать нечего, версии у исхода нет. HTTP-ответ — 204 без
тела и без `Preference-Applied`. Команда одного агрегата, чей `decide` не дал событий, сохраняет
форму `{:projected | :accepted, id, version}`. Дополняет ADR-0039 и ADR-0047: те знали исходы
только с записью. Норма — `docs/rules/app/10-architecture.md`, «Usecases»;
`docs/rules/app/15-web-api.md`, «Ожидание проекции».

## Контекст

Факты на 2026-10-03 (адаптация потребителя A к rc после 0.10.0):

- у потребителя A выдача ролей пачкой заводит поток при ожидаемой версии `:current` и при пустом
  списке возвращает `{:ok, nil}`: поток может быть не заведён, версии нет;
- таблица возвратов знала команду (`:projected` с представлением, `:accepted` с `{id, version}`) и
  создание (`{id, version}` в обоих исходах) — форме без версии места не было;
- в API 200 значит «`GET` по `id` уже видит запись», 202 — «ещё не видит» (ADR-0030);
- команда одного агрегата без событий проходит запись без изменений: поток есть, версия известна,
  ожидание завершается сразу.

## Рассмотренные варианты

- **Пустой пакет — ошибка домена (422).** Отвергнут: клиент, который снял все отметки, сделал
  допустимую операцию, а не ошибку ввода.
- **Прочитать текущую версию и отдать `{:accepted, id, version}`.** Отвергнут: лишнее чтение ради
  формы, а у незаведённого потока версии нет вовсе.
- **`:unchanged` у любой команды без записи.** Отвергнут: команда одного агрегата отняла бы у
  клиента версию для следующего `If-Match`.
- **200 или 202 на `:unchanged`.** Отвергнут: оба утверждают что-то о записи, которой не было.

## Решение

- `{:ok, :unchanged}` — только у пакетной команды с пустым пакетом;
- HTTP — 204 без тела и без `Preference-Applied`; операция объявляет ответ 204;
- команда одного агрегата без событий — прежняя форма с версией.

## Цена

- **Ещё один тег исхода:** хелпер ответа и тесты клиента различают три исхода вместо двух.
- **Граница «пакетная команда» держится ревью:** сборка не отличает её от обычной.
