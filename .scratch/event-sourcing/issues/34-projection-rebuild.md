# 34: Пересборка проекции подъёмом `version:`

**What to build:** автор проекции поднимает `version:` — и после выкладки проекция сама очищает read-модель и прогоняет
историю заново, а старая нода, увидев чекпоинт новее своей версии, пропускает работу. Для пересборки без окна неполных
данных свод даёт рецепт новой проекции, а строку чекпоинта удалённой проекции убирает миграция потребителя.

**Blocked by:** [33: Проекция: объявление и синхронная пачка](33-projection-batch.md)

**Status:** resolved

**Spec:** [Event-sourced агрегат в :core](../spec.md) — «Проекции: объявление, пачка, ожидание,
пересборка», ADR-0011

- [x] В транзакции пачки: строки чекпоинта нет или её версия меньше `version:` → `clear/0` → чекпоинт в начало со
      своей версией и целью (максимальная позиция с `xid < pg_snapshot_xmin`, пустое хранилище — `nil`) → CAS →
      `info` `projection= from_version= to_version=` → `:processed`.
- [x] Версия строки больше `version:` → `:outdated`, события не читаются.
- [x] Пересборка идёт, пока чекпоинт < цели; достижение цели — `info`.
- [x] `run_once` → `… | :outdated`; `run_until_idle` → `{:error, :outdated}`.
- [x] Ошибка или исключение `clear/0` — откат, строка чекпоинта не меняется.
- [x] `Core.Es.Migration.delete_checkpoint/1` для миграции потребителя; библиотека строки сама не удаляет.
- [x] Тесты: подъём `version:` очищает read-модель и строит её заново с достижением цели; строка с версией выше —
      `:outdated`; ошибка `clear/0`; `delete_checkpoint/1`; ручной `DELETE` строки — старт с начала.
- [x] `22-projections.md`: «Версия и пересборка» (когда MUST поднять `version:`; SHOULD расширяющая миграция таблиц,
      несовместимая — новая проекция); «Новая проекция» (три выкладки; MUST NOT удалять таблицы в выкладке, убирающей
      модуль или читающий их ReadRepo); «Удаление» (`delete_checkpoint/1`, имя MUST NOT переиспользовать).
      `CHANGELOG.md`, «Новое».
- [x] `make` зелёный.

## Comments

- 2026-09-14 — реализация:
  - цель пересборки — последняя позиция событий **типов агрегатов проекции**, а не всего `es_events`:
    чекпоинт встаёт только на позиции своих событий, и цель по всему хранилищу была бы недостижима.
    Видимость та же, что у чтения пачки (`xid < pg_snapshot_xmin OR xid = pg_current_xact_id_if_assigned()`):
    в sandbox теста цель — записанное самим тестом, у пачки сброса на проде своих событий нет.
    Запрос — `@doc false` `Core.Es.Store.last_position/2` поверх общего с `list_after/4` предиката;
  - цель по достижении не стирается; «достигнута» — пачка, которая перевела чекпоинт с позиции ниже цели на
    цель или дальше. Пустая цель — `info` о достижении пишет сама пачка сброса: иначе новая проекция на
    пустом хранилище не дала бы признака «догнала»;
  - сброс строки с версией ниже — CAS `UPDATE` по прочитанной строке (позиция и версия), без строки —
    прежний `INSERT … ON CONFLICT DO NOTHING`; обе ветки — `Checkpoint.start/3`. У сброса со строкой
    `core.es.checkpoint.from` span'а — прежняя позиция строки;
  - `info`: `проекция: старт с начала истории: projection= from_version= to_version=` (без строки —
    `from_version=nil`) и `проекция: цель пересборки достигнута: projection= version=`;
  - `:outdated` в `run_once` не логируется: `warning` один раз при переходе в пропуск — состояние читателя (35);
  - `delete_checkpoint/1` — `execute(fn -> repo().query!(sql, [name]) end)`: имя уходит параметром, запрос
    выполняется после колбэка миграции; в `change/0` откат — `Ecto.MigrationError`. Тест —
    `Ecto.Migrator.up(…, migration_lock: false)`: блокировка миграций держит соединение sandbox, которого
    ждёт процесс миграции;
  - сверх пунктов: README — строка про `delete_checkpoint/1`; строки карт `00-index.md` и `AGENTS.md`;
    `description` skill `projections`; moduledoc `Core.Es.Projection` — раздел «Пересборка».
- 2026-09-14 — по ревью:
  - `Checkpoint.columns/1` вместо тройного `|| {nil, nil}`; moduledoc `Core.Es.Migration` — чекпоинты и
    `delete_checkpoint/1`; хелпер теста `checkpoint!` — плоские колонки цели; тест пустого хранилища слит с
    «первой пачкой»;
  - `22-projections.md`: SHOULD у трёх выкладок, примеры понижения `version:` и лишнего подъёма;
  - тест подъёма `version:` — последнее событие хранилища чужого типа: цель — событие типов проекции, и она
    достигается; `FailingClear` стирает строки read-модели до отказа — откат их возвращает;
  - `spec.md`, пункт «Пачка» — цель по типам проекции с видимостью чтения пачки; ADR-0011 неизменен, его
    «максимальная позиция ниже `pg_snapshot_xmin`» — без уточнения типов;
  - оставлено: `info` старта и достижения цели пишутся после CAS внутри транзакции пачки — в span'е, как
    `warning` исключения; сорванный commit повторит `info` в следующей пачке. CAS-конфликт сброса
    существующей строки тестом не покрыт — тот же `compare_and_set`, что у `move` с тестом
    `:checkpoint_conflict`. Повтор «библиотека строк сама не удаляет» в README, CHANGELOG и moduledoc — у
    них разные читатели.
