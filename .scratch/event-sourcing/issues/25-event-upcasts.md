# 25: Апкаст событий в кодеке агрегата

**What to build:** автор домена меняет схему события несовместимо — заводит новый тег и объявляет у кодека
`upcasts: %{"старый тег" => "новый тег"}` с колбэком `upcast/2`. Всякий, кто грузит события через фасад (подписчик
брокера, тесты, а позже свёртка агрегата, проекции и страница потока), получает записанное событие старого тега уже как
событие текущего модуля. Записанные строки не переписываются.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Spec:** [Event-sourced агрегат в :core](../spec.md) — «Кодек событий (`Core.Es.Event.Codec`)»,
ADR-0010

- [ ] `use Core.Es.Event.Codec` принимает `upcasts:`; при непустой карте обязателен колбэк
      `upcast(old_tag, envelope)` → нагрузка.
- [ ] Апкаст срабатывает в `load_by_tag` до выбора модуля и идёт цепочкой по шагам (v1 → v2 → v3); меняются только
      тег и нагрузка, заголовок (`event_id`, `aggregate_id`, `aggregate_version`, `at`, `by`) колбэк только читает;
      одно записанное событие — ровно одно прочитанное; ошибку формы нагрузки ловит `load_payload`.
- [ ] `CompileError`: источник есть в `tags:`; цель не в `tags:` и не является источником; цикл в карте; колбэка нет
      при непустой карте.
- [ ] Переименование тега — клауза `upcast/2`, возвращающая нагрузку как есть.
- [ ] Интроспекция `__es_mods__/0` (модули из `tags:`) и `__es_upcasts__/0` (карта как объявлена); `types/0`,
      `mod_by_tag/1` и публичная `to_fields/1` не меняются.
- [ ] Тесты: события v1 и v2 грузятся через фасад в модуль v3; переименование тега; каждый `CompileError`; тег вне
      `tags:` и `upcasts:` — `:unknown_event_type`.
- [ ] `14-events-outbox.md`: таблица «Совместимость событий» из спеки (включая удаление типа без замены: тег остаётся
      в `tags:`, писать перестают); MUST NOT изменять записанные строки хранилища событий; «тег остаётся в кодеке
      навсегда — в `tags:` или в `upcasts:`»; ужесточение проверок Prim в нагрузке и заголовке — MUST NOT; правило
      «upcast по `aggregate_version`» удалено.
- [ ] `CHANGELOG.md`, «Новое»: `upcasts:` + `upcast/2`.
- [ ] `make` зелёный.
