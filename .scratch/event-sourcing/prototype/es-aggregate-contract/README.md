# PROTOTYPE · Контракт event-sourced агрегата

Тикет: [Контракт event-sourced агрегата](../../issues/05-prototype-aggregate-contract.md). Одноразовый код:
в `lib/` переносится только решение, не этот код.

## Вопрос

Как для автора домена выглядит event-sourced агрегат в `:core` — на одном синтетическом «Черновике»
(`new → in_approving → approved`) в двух стилях:

- **A · мутация записывает событие** — мутации `{:ok, draft} | {:error, _}`, как у state-stored агрегата;
  состояние меняет только `apply_event/2` — и в мутации (`record/5`), и при восстановлении из истории;
- **B · decider** — `initial_state/0`, `decide(команда, состояние)` → события, `evolve(состояние, событие)`.

В обоих стилях версию события назначает библиотека, агрегат `Version` не трогает.

## Запуск

```bash
mix run --no-start .scratch/event-sourcing/prototype/es-aggregate-contract/run.exs
```

## Что сравнивать

| Файл | Что внутри |
|---|---|
| `style_a.exs` | A: агрегат, заглушки репозитория и usecase |
| `style_b.exs` | B: агрегат с командами, заглушки репозитория и usecase |
| `common.exs` | общие события и ошибки, «библиотека» обоих стилей (`Proto.Es*`), хранилище в памяти, печать |
| `run.exs` | сценарии на обоих стилях |

## Сценарии

1. Счастливый путь: создать → переименовать → отправить → согласовать; восстановление = состояние после мутации.
2. Недопустимая операция: согласовать черновик в статусе `:new`.
3. Операция без изменений: переименовать в то же название.
4. Два события из одной команды: отправка с автосогласованием.
5. Конкурентная запись: оба прочитали v2.
6. Пустой поток: свёртка `[]`, чтение и команда по несуществующему id, повторное создание.

## Вердикт

Стиль B (decider) с поправками прототипа:

- `decide` возвращает `{Event.Mod, payload}` / `Event.Mod` без `id`, версии, `by`, `at` — их ставит библиотека,
  помощник `stamp` в clause не нужен;
- `initial_state/0` нет — `%__MODULE__{}` с `id` из адреса; `id` из команды создания уходит;
- команды — `<Aggregate>.Cmd.<Name>` с `use Core.Es.Cmd`;
- ручная свёртка сценария 4 остаётся, но через `fold/3`.

Решение — [Контракт event-sourced агрегата](../../issues/05-prototype-aggregate-contract.md).
