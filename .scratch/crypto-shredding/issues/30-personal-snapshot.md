# 30: Снапшот агрегата с ПДн

**What to build:** агрегат-лицо (у всех ПДн-полей `subject: :aggregate_id`) пользуется снапшотами как раньше, но
снапшот шифруется под ключом субъекта. После уничтожения ключа поток сворачивается целиком, и новый снапшот не
пишется. Если субъект — поле нагрузки, `snapshot:` запрещён сборкой.

**Blocked by:**
- [23: ПДн-значение в `es_events` и outbox: шифрование и расшифровка](23-personal-value-in-events-and-outbox.md)

**Status:** resolved

**Spec:** [Crypto-shredding: ПДн в событиях под ключом субъекта](../spec.md) — «Снапшоты»; ADR-0076

- [x] `snapshot:` у агрегата с ПДн в событиях допустим, только если у всех ПДн-полей `subject: :aggregate_id`. Иначе
      — `CompileError` в `use Core.Es.Aggregate.Repo.Pg`; тест — модулем внутри теста.
- [x] Снапшот такого агрегата шифруется всегда:
      - `term_to_binary` состояния целиком — одно ПДн-значение субъекта `aggregate_id`, через `seal` / `open`;
      - AAD — тип агрегата, id, версия и маркер;
      - признак шифрованного снапшота входит в маркер;
      - схема `es_snapshots` и опции `snapshot: [every:, version:]` не меняются.
- [x] Чтение — одной пачкой `open` с хвостом событий:
      - `:destroyed` — `:rejected` на `debug` и полная свёртка с уничтоженными значениями;
      - `:unreadable` — `:rejected`, `warning` и полная свёртка без `Core.Exc`;
      - сбой хранилища — ошибка вызывающему.
- [x] Запись — после commit, вне транзакции `append`:
      - ключа нет — `seal` создаёт его своим запросом;
      - `:subject_destroyed` — снапшот не пишется, лог `debug`;
      - если чтение уже видело уничтоженный снапшот или значение, запись не пытается.
- [x] Тесты на `Account.Repo.Pg.Snapshotted`:
      - прямой `SELECT` — в `state` нет открытого текста;
      - после `destroy_key/3` — полная свёртка и ни одного нового снапшота;
      - подменённый шифротекст — `warning` и верное состояние;
      - сбой порта — ошибка;
      - нынешний контрактный набор зелёный.
- [x] Свод:
      - `13-repos.md` «Снапшоты» — только `subject: :aggregate_id`, чтение и запись после уничтожения;
      - app/13 «Снапшоты» — ссылка на 23.
- [x] `CHANGELOG.md`:
      - сквозной пункт — шифрованный снапшот;
      - «Изменения контракта макросов» — `CompileError` на `snapshot:`.
- [x] `make` зелёный.
