# 22: Уничтожение ключа субъекта

**What to build:** usecase уничтожает ключ субъекта одним вызовом `Core.Es.Personal.destroy_key(subject_id, by,
context)` в своей транзакции.
- Ключ уничтожен в момент commit, повтор отвечает `:ok`.
- В той же транзакции в поток субъекта в `es_events` пишется событие уничтожения ключа.

Читать события с уничтоженными значениями научит тикет 23, проекции — тикет 32.

**Blocked by:** [20: Хранилище ключей: порт и встроенная реализация](20-key-store.md)

**Status:** ready-for-agent

**Spec:** [Crypto-shredding: ПДн в событиях под ключом субъекта](../spec.md) — «Уничтожение ключа субъекта
(`Core.Es.Personal.destroy_key/3`)»; ADR-0076, ADR-0079

- [ ] Сигнатура `destroy_key(subject_id, by, context)` → `Result.unit()`:
      - `subject_id` и `by` — UUID-Prim, проверяются guard'ами в голове;
      - сбой хранилища — `{:error, %Error{kind: :app}}`.
- [ ] Транзакция — вызывающего, если открыта, иначе своя. Внутри:
      - `destroy` порта;
      - событие уничтожения ключа — если его нет в потоке субъекта, независимо от ответа порта.

      Повтор при уже записанном событии — `:ok` без записи; субъект без ключа получает строку-след.
- [ ] Событие уничтожения ключа:
      - `Core.Es.Personal.Event.KeyDestroyed` кодека `Core.Es.Personal.Event.Codec`;
      - `type: "core.subject"`, тег `"core.subject.key_destroyed"`;
      - `aggregate_id` — `Core.Es.Personal.SubjectID`, версия `1`, нагрузка пуста;
      - `by` — `Core.Es.Personal.ActorID`, `at` — `Es.Event.At` в момент вызова;
      - пишет его `Core.Es.Store.append`, в outbox оно не идёт.
- [ ] Кодек события библиотека подключает к фасаду кодека потребителя сама. Дубль `type: "core.subject"` у кодека
      потребителя — `CompileError`. `page_stream` поток субъекта не отдаёт.
- [ ] Лог `debug` — `"ключ субъекта уничтожен: subject_id=… event_written=…"`, без автора. Отказ порта уходит
      вызывающему без лога.
- [ ] Тесты, `Core.DataCase`:
      - строка-след и событие (`events!`);
      - повтор — `:ok` без второго события;
      - субъект без ключа;
      - откат транзакции вызывающего убирает и след, и событие;
      - сбой порта (подменённая реализация) — ошибка без события;
      - `CompileError` на дубль `type:`.
- [ ] Golden события — свой тест-модуль `use Core.Es.EventCompatCase` над `Core.Es.Personal.Event.Codec`, фикстура в
      каталоге зарезервированного типа.
