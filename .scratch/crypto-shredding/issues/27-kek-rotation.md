# 27: Ротация KEK

**What to build:** оператор переводит ключи субъектов на новый KEK без простоя. Перевёртку обёрток делает функция
встроенной реализации или mix-задача поверх неё; статус показывает, сколько живых ключей осталось под каждой версией
KEK, чтобы старый KEK удалить, когда под ним ноль.

**Blocked by:** [20: Хранилище ключей: порт и встроенная реализация](20-key-store.md)

**Status:** ready-for-agent

**Spec:** [Crypto-shredding: ПДн в событиях под ключом субъекта](../spec.md) — «Встроенная реализация» (перевёртка,
статус, секрет индекса); ADR-0075, ADR-0077

- [ ] `Core.Es.Personal.KeyStore.Pg.rewrap(opts)` → `Result.t(non_neg_integer())` — число перевёрнутых ключей:
      - пачка живых ключей под нетекущей версией (`batch_size:`, по умолчанию 500) — в своей транзакции, `FOR UPDATE`
        в порядке идентификатора, без `SKIP LOCKED`;
      - обёртка текущим KEK с новым nonce, AAD — идентификатор ключа и новая версия;
      - цикл до пустой пачки, повторный запуск продолжает с места остановки;
      - обрыв пачки — ошибка без повтора внутри; `Es.Transact` не участвует.
- [ ] `status/0` — число живых ключей по версиям KEK; строки-следы не в счёт.
- [ ] `mix es.personal.rewrap` поверх обеих функций, по образцу `mix outbox.requeue`: печатает статус и прогресс после
      каждой пачки. В релизе — через `eval`.
- [ ] Метрик и span'ов нет.
- [ ] Тесты:
      - конфигурация с двумя версиями: `rewrap` переводит ключи, `open` после перевёртки работает;
      - продолжение после прерванного прогона;
      - `status/0` до и после, следы не считаются;
      - удаление старой версии до перевёртки даёт `:kek_unknown`.
- [ ] Свод:
      - 23 «Хранилище ключей» — перевёртка и статус;
      - app/23 «Эксплуатация» — runbook ротации:
        1. новый KEK — на все ноды;
        2. `current_kek` — на все ноды;
        3. перевёртка;
        4. когда под старой версией ноль, старый KEK удаляется не раньше, чем истекут копии, нужные для
           восстановления;
      - app/23 «Эксплуатация» — хранение и копирование секрета индекса наравне с KEK; при компрометации — перевод на
        новую область.
- [ ] `CHANGELOG.md`, сквозной пункт: перевёртка, статус и mix-задача.
- [ ] `make` зелёный.
