# 26: Страница событий: ПДн-значение клиенту

**What to build:** клиент страницы событий получает живое ПДн-значение открытым wire-значением — права проверил
usecase, — а уничтоженное — как `{"$destroyed": true}`. Форму описывает схема `payload`. Свой
`Jason.encode(OutCodec.dump(event))` в обход `Core.Web.Event` падает на маркере.

**Blocked by:**
- [21: ПДн-поле нагрузки: `subject:`, маркер и уничтоженное значение в кодеке](21-payload-subject-marker.md)
- [24: Golden-фикстуры: уничтоженный вариант и построители тестов](24-golden-fixture-destroyed-variant.md)

**Status:** ready-for-agent

**Spec:** [Crypto-shredding: ПДн в событиях под ключом субъекта](../spec.md) — «Страница событий
(`Core.Web.Event`)»; ADR-0074

- [ ] `Core.Web.Event` снимает маркеры после `codec.dump` внешним профилем:
      - живое ПДн-значение — открытым wire-значением;
      - уничтоженное — `{"$destroyed": true}`; ключ `$destroyed` переживает `camelize`.
- [ ] Схема `payload` описывает форму уничтоженного значения.
- [ ] `Jason.encode` дампа в обход `Core.Web.Event` падает на маркере, и значения в тексте ошибки нет.
- [ ] Сведения события (`labels: true`) не падают на поле с `%Destroyed{}`.
- [ ] Тесты на событиях из `destroyed/2` и на живых событиях, без БД.
- [ ] Свод:
      - app/15 «Событие страницы событий» — живое ПДн открыто под правом usecase, уничтоженное —
        `{"$destroyed": true}`;
      - 23 «Уничтоженное ПДн-значение» — форма для клиента.
- [ ] `CHANGELOG.md`, сквозной пункт: `{"$destroyed": true}` как контракт клиента страницы событий.
- [ ] `make` зелёный.
