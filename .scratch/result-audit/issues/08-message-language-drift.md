## Agent Brief

**Category:** enhancement
**Summary:** выровнять язык сообщения `Core.Option.unwrap!/1` с `Core.Result.unwrap!/1` — русский текст

**Current behavior:**
`Core.Result.unwrap!/1` на причине не-`%Error{}` поднимает `ArgumentError` с русским текстом, где
названы функция и причина. Одноимённая `Core.Option.unwrap!/1` на `nil` поднимает `ArgumentError`
с английским текстом. Это единственный английский текст сообщения в библиотеке: остальные `raise`
переведены коммитом `bd4cef3`, который `Core.Option` не тронул. Два модуля-близнеца, которые
потребитель зовёт вперемежку, печатают падение на разных языках.

**Desired behavior:**
`Core.Option.unwrap!/1` поднимает `ArgumentError` с русским текстом той же формы, что у близнеца:
названа функция с арностью, названа причина падения (`nil`). Класс исключения, сигнатура и поведение
обеих клоз не меняются. Английских текстов сообщений в `lib/` не остаётся.

**Key interfaces:**
- `Core.Option.unwrap!/1`, клоза на `nil`: меняется только строка сообщения `ArgumentError`;
  образец формы — сообщение `Core.Result.unwrap!/1` (`"Result.unwrap!/1 вызван на ошибке: …"`),
  префикс — короткое имя модуля без `Core.`. `inspect/1` здесь не нужен: причина падения — сам `nil`;
- `Core.Option.expect!/2` не трогается: текст задаёт вызывающий (и функцию удаляет тикет 03).
