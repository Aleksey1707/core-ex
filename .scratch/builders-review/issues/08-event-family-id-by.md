# 08: Событие — `aggregate_id` / `by` на семейство, одна ветка `quote`

**Status:** ready-for-human

**Blocked by:** None. Обсуждается вместе с 07.

**Сила:** Worth exploring. Для потребителей изменение ломающее.

**Файлы:** `lib/core/es/event.ex` (~97–245), `lib/core/es/event/codec.ex` (`derive!`).

**Проблема.**
- Каждое событие повторяет `aggregate_id:` и `by:` (у агрегата счёта в фикстуре это 5×2), а кодек затем проверяет, что все значения совпадают.
- `quote bind_quoted` содержит `if is_nil(payload_mod)` с двумя почти одинаковыми ветками `@type` / `draft` / `new`, примерно по 55 строк.
- Опции разбираются в теле модуля, а у `Aggregate` / `Cmd` — при раскрытии макроса.

**Что изменилось бы.** `aggregate_id` и `by` объявляются один раз на семейство событий, а шаблон события становится одной веткой.

**Выигрыш.** Меньше мест для правки и меньше сгенерированного кода. Литеральные головы `%AggID{}` по ADR-0014 сохраняются.

**ADR.** ADR-0014: литеральные головы должны остаться. Изменение ломающее, нужна запись в CHANGELOG.
