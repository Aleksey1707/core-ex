## Agent Brief

**Category:** enhancement
**Summary:** AST-разбор ручных клауз Codec-плагина уходит из `Core.Codec.Plugin.Opts` в отдельный module.

**Current behavior:**
- `Core.Codec.Plugin.Opts` назван «опции», но держит два понятия:
  - разбор опций `use Core.Codec.Plugin` (`types!/1`, `all_types!/2`, `union!/2`) и проверку
    покрытия перед сборкой;
  - разбор AST ручных клауз через `Module.get_definition/2`: `manual_targets/4` (на какие типы
    матчит клауза — по паттерну головы и guard'ам), `raise_never_match!/3`, `raise_specs!/3`.
- Второе использует и `Core.Codec.Plugin.Redump` (`redump_spec/1`) — то есть зовёт «опции» ради
  разбора клауз.

**Desired behavior:**
- Разбор ручных клауз — отдельный module под `Core.Codec.Plugin` (имя — по выбору, например
  `Core.Codec.Plugin.Clauses`) с `@moduledoc`: что он разбирает и какие формы головы / guard'ов понимает.
- `Plugin.Opts` и `Plugin.Redump` зовут его; `Plugin.Opts` держит только опции и проверку покрытия,
  его `@moduledoc` перестаёт описывать разбор клауз.
- Поведение и тексты всех `CompileError` не меняются.

**Key interfaces:**
- `manual_targets/4`, `raise_never_match!/3`, `raise_specs!/3` — переезжают с теми же сигнатурами и
  `@spec`; приватные хелперы разбора (`target`, `guard_targets`, `in_guard`, `manual_specs`, …) — с ними.
- Разметка модулей — по `make layout-check`.

**Acceptance criteria:**
- [ ] В `Core.Codec.Plugin.Opts` нет `Module.get_definition` и разбора паттернов / guard'ов.
- [ ] Существующие тесты плагина и redump (ручные клаузы, never match, `@spec` у генерируемых
      функций) зелёные без правки ожидаемых текстов.
- [ ] CHANGELOG не меняется (внутренний модуль).
- [ ] `make` зелёный, включая `xref` (нет нового цикла компиляции) и `consumer-check`.

**Out of scope:**
- `__codec_redump_missing__/0` и `Codec.Facade.redump?/1` — оставлены сознательно
  (`.out-of-scope/codec-redump-missing-reflection.md`).
- Поиск ручных клауз нагрузки в `Es.Event.Codec` (`manual_payload_funs`): он только находит клаузы,
  чтобы запретить их, а не разбирает цели, — переводить на новый module не нужно.
