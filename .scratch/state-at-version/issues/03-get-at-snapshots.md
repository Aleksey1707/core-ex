# 03: `get_at` над write-репозиторием со снапшотами

**What to build:** read-модель по версии над write-репозиторием с `snapshot:` читает состояние на версии
верно и быстро там, где это возможно: снапшот с версией не выше `N` — начало свёртки, снапшот новее `N`
пропускается и свёртка идёт с начала потока, чтение снапшот никогда не пишет и свежий снапшот не затирает.
Зашифрованный снапшот агрегата с ПДн читается тем же путём, что у `get`. Спека
`.scratch/state-at-version/spec.md`, ADR-0094.

**Blocked by:** 02 (`get_at` над write-репозиторием без снапшотов).

**Status:** ready-for-agent

- [ ] Фикстура read-модели по версии над вариантом write-репозитория со снапшотами; контрактный набор `get_at` из 02 гоняется и на ней.
- [ ] Снапшот на версии ≤ `N`: View совпадает с полной свёрткой до `N`; telemetry `[:es, :aggregate, :fold]` показывает хвост от снапшота.
- [ ] Снапшот новее `N`: View совпадает с полной свёрткой до `N`, свёртка — с начала потока.
- [ ] После `get_at` снапшот в хранилище не изменился (ни версия, ни состояние), в том числе когда хвост длиннее `every`.
- [ ] Зашифрованный снапшот с ПДн: до и после уничтожения ключа субъекта исход тот же, что у `get` на той же версии.
- [ ] Раздел «Состояние на версии» в `13-repos.md` и пункт CHANGELOG из 02 дополнены поведением снапшотов, новых пунктов не заведено.
- [ ] `make` зелёный.
