# 04: `get_many_at`

**What to build:** read-модель по версии отдаёт представления по списку адресов версий одним запросом:
`get_many_at([{%Agg.ID{}, %Version{}}], %Context{}, opts \\ [])` → `{:ok, [%View{}]}` в порядке пар. Один
агрегат можно указать на разных версиях и повторять одну пару; поток каждого id читается один раз до
наибольшей версии его пар, состояние снимается на каждой запрошенной. Спека
`.scratch/state-at-version/spec.md`, ADR-0094.

**Blocked by:** 03 (`get_at` над write-репозиторием со снапшотами).

**Status:** claimed

- [ ] Behaviour объявляет колбэки `get_many_at/2,3` с сужением до `{:ok, [%View{}]} | {:error, %Error{}}`; реализация `defoverridable`.
- [ ] Результат — в порядке пар; разные версии одного id и одинаковые пары разрешены, каждая пара получает свой View.
- [ ] Поток каждого уникального id читается один раз до наибольшей версии его пар (один запрос на пакет без снапшотов; со снапшотами — снапшот ≤ наименьшей версии пар id или поток с начала).
- [ ] Все адреса за головой потока и пустые потоки — одна `:version_mismatch` со списком detail `source: :address` в порядке пар.
- [ ] `[]` — `{:ok, []}` без запросов; элемент не пара `{%Agg.ID{}, %Version{}}` (в том числе `:current`) — `FunctionClauseError`.
- [ ] Снапшоты не пишутся; telemetry с `op: :get_many_at`.
- [ ] Контрактный набор `get_many_at` на обеих фикстурах (без снапшотов и со снапшотами).
- [ ] Раздел «Состояние на версии» в `13-repos.md`, `21-observability.md` и пункт CHANGELOG дополнены `get_many_at`, новых пунктов не заведено.
- [ ] `make` зелёный.
