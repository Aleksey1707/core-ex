# 06: Сужение результата read-репозитория по версии у потребителя

**What to build:** у вызывающего компилятор знает форму результата `get_at` / `get_many_at`: опечатка в поле
View и невозможная clause по результату дают предупреждение при сборке. Это фиксирует фикстура-потребитель
маркерами `# expect:` (ADR-0014), чтобы будущая правка макроса не потеряла сужение молча. Спека
`.scratch/state-at-version/spec.md`, ADR-0094.

**Blocked by:** 04 (`get_many_at`).

**Status:** resolved

- [ ] В фикстуре-потребителе — read-модель по назначению над её event-sourced агрегатом: behaviour, реализация, View и `to_view`, в каталоге агрегата по SHOULD свода.
- [ ] Маркеры `# expect:` на опечатку в поле View результата `get_at` и элемента `get_many_at` и на невозможную clause по результату обоих.
- [ ] `boundary_lint --consumer` и `spec_lint` над фикстурой проходят; `make consumer-check` зелёный.
- [ ] `make` зелёный.
