# 12: Свободная jsonb-map во View — `type: :map`

> *This was generated by AI during triage.*

**Status:** resolved

**Blocked by:** —

**Проблема:** во View нет вида поля для jsonb, которую переводить не нужно, — словаря строк или свободной
map. Такое поле объявляется только `jsonb: {Mod, :fun}`, и под него заводят функцию с пустой спекой
`{:map, %{}}`. На 2026-10-11 таких спек 6 из 15 у потребителей (A — 1, B — 2, E — 3). Все существуют
только ради View, у E — в доменных модулях. Выделено из `11-derived-redump.md` при разборе.

## Agent Brief

**Category:** enhancement
**Summary:** `Core.View` принимает `type: :map` — jsonb-поле без пере-дампа с типом `map()`.

**Current behavior:**
`type:` у `Core.View` — скаляры `:string` / `:boolean` / `:integer` / `:pos_integer` / `:non_neg_integer`.
jsonb-поле объявляется только `jsonb: {Mod, :fun}` со спекой `Core.Codec.Redump`. Форма, в которой
переводить нечего, требует функции с пустой спекой `{:map, %{}}`. Спека полей Codec-плагина `:map` в
`type:` уже принимает.

**Desired behavior:**
- `type: :map` у `Core.View` — в `fields:`, `forms:` и элементом `list:`. Значение уходит в дамп как
  есть. Тип поля — `map()` (`map() | nil` при `optional:`), элементом списка — `[map()]`.
- Неизвестный `type:` по-прежнему `CompileError`; в тексте среди допустимых — `:map`.
- Норма: `type: :map` MAY только для формы без форматируемых Prim (`:uuid` / `:datetime` / `:date` /
  `:decimal`) на любой глубине; форма с ними — `jsonb:`. Сверочный тест read-wire к полю `type: :map`
  не применяется: переводить в нём нечего.

**Key interfaces:**
- вид поля `type:` у `Core.View` (`fields:`, `forms:`, `list:`) — значение `:map`;
- `@type t` представления и `@type` форм — `map()` для такого поля.

      фикстуру-потребителя, как у остальных видов).
- [x] Текст `CompileError` на неизвестный `type:` перечисляет `:map`.
