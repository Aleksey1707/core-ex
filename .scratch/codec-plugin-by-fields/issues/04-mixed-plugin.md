# 04: Смешанный плагин — типы по полям и ручные клаузы

**Status:** ready-for-agent

**Blocked by:** 02.

**What to build:** автор многотипового плагина объявляет по полям только типы, повторяющие wire, а нетривиальный
тип пишет руками в том же плагине; двух источников wire для одного типа быть не может. Спека — `../spec.md`,
«`use Core.Codec.Plugin, fields:`»; ADR-0056.

- [ ] Типы вне `fields:` обслуживаются ручными клаузами `dump/2` / `load/3`; сгенерированные и ручные клаузы — одна
      функция без предупреждения о негруппированных клаузах у потребителя.
- [ ] Ручная клауза на тип из `fields:` — предупреждение «never match».
- [ ] Тип из `types:` без спеки и без ручной клаузы — `CompileError` (расширение проверки «требуется dump/2»; при
      `loadable: true` — и для `load/3`).
- [ ] `loadable: false` с `fields:` — генерируется только `dump/2`.
- [ ] `union:` с `fields:`: варианты по полям, клауза `load(Family, ...)` — руками; `InCodec.load(Family, wire)`
      восстанавливает вариант.
- [ ] Тесты фасада: смешанный плагин, dump-only плагин по полям, union с вариантами по полям; тесты сборки:
      непокрытый тип.
- [ ] `fixtures/consumer`: `# expect:` на ручную клаузу для типа из `fields:`.
- [ ] `docs/rules/11-domain.md`: смешение в одном плагине, `loadable: false`, `union:`.
- [ ] `CHANGELOG.md`: дополняется пункт о плагине по полям.
- [ ] `make` зелёный.
