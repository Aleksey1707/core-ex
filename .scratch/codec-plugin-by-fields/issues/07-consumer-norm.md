# 07: Норма потребителя и тестов для плагина по полям

**Status:** resolved

**Blocked by:** 04, 06.

**What to build:** ярус потребителя требует объявлять по полям тип, совпадающий с wire один к одному, а свод тестов —
round-trip и golden-фикстуры и для объявленных по полям типов. Спека — `../spec.md`, «Нормы и документация»;
ADR-0056.

- [x] `docs/rules/app/11-domain.md`: SHOULD — тип, совпадающий с wire один к одному, объявляется по полям (плагин
      `fields:`, нагрузка `Core.Es.Event.Payload`); ручной плагин — для расхождения сильнее переименования ключа;
      нагрузка value object — одной строкой через фасад.
- [x] `docs/rules/19-testing.md`, «Codec: round-trip»: round-trip обязателен и для плагина по полям (проверяет
      объявление автора); golden-фикстуры событий с нагрузкой по полям — как для ручных (переименование поля молча
      меняет wire).
- [x] Ссылка ADR-0056 на нормы ведёт в существующие разделы.
- [x] `CHANGELOG.md` тем же коммитом: пункт о норме `app/**` с «было → стало» для кода потребителя.
- [x] `make rules-check` и `make` зелёные.
