# 08: Варианты union — адресом и спекой (бывш. «с конвертом — по полям»)

**Status:** ready-for-agent

**Blocked by:** —

**Проблема:** у потребителя A семейство из 13 вариантов пишет wire варианта конвертом
`%{"type" => <код>, "fields" => %{…}}`, и большинство вариантов внутри конверта повторяют поля один к одному.
Сгенерированный `dump/2` варианта по `fields:` отдаёт плоскую map, а `load/3` ждёт её же, поэтому вставить его в
конверт нельзя: все варианты остаются ручными целиком. ADR-0056 оставил разбор тега union ручной клаузой
`load(Family, ...)`, а декларативный `tags:` — до повторения разбора; конверт — третья форма, которой нет ни там,
ни там.

**Варианты для разбора:**

- генерация только «полей»: публичные `dump_fields/2` / `load_fields/3` типа из `fields:` без регистрации типа в
  `dump/2` / `load/3`, а конверт и выбор варианта пишутся руками;
- опция конверта у плагина (`envelope: {"type", "fields"}` + код варианта в спеке): конверт и разбор тега генерирует
  библиотека — пересекается с отложенным `tags:`;
- оставить ручным и записать в ADR-0056 как известное ограничение.

**Нужно до реализации:** выбрать вариант (решение ADR — дополнение к ADR-0056 или новый ADR), сверить с формой
union у остальных потребителей (кто ещё пишет конверт, кто — тег внутри данных).

## Agent Brief

**Category:** enhancement
**Summary:** `Core.Codec.Plugin`: варианты семейства объявляются `variants:` адресом и спекой полей; дамп в форме
адреса, симметричная загрузка варианта, загрузка по семейству, `type/1` / `types/0` и ошибки разбора генерируются;
`types:` — только ручные типы.

**Current behavior:**
`types:` обязателен и перечисляет все типы плагина; ключи `fields:` — его подмножество. `union: Family` требует
ручную клаузу `load(Family, wire, codec)`: таблицу тег ↔ модуль, разбор формы, выбор варианта и ошибки автор пишет
сам, `dump/2` варианта в тегированной форме — тоже. Тип из `fields:` получает клаузы с плоской map, ручная клауза на
него — `CompileError`, поэтому вариант в тегированной форме по полям не объявить.

**Desired behavior:**

Объявление:

- `variants: [{Mod, адрес, spec} | {Mod, адрес}]` требует `union:` (иначе `CompileError`); `union:` без
  `variants:` ведёт себя как прежде. `spec` — та же форма и те же проверки, что у `fields:` (сверка ключей со struct,
  виды полей, `wire:`, `optional:`, `default:`), за вычетом поля дискриминатора.
- Типы плагина (`__codec_types__/0`) — `types:` ∪ ключи `fields:` ∪ модули `variants:`. `types:` перечисляет только
  ручные типы и MAY отсутствовать; тип в двух опциях — `CompileError` с именем плагина и типа; пустой итог —
  `CompileError`.
- Адрес варианта — одна из форм:
  - `"tag"` — тегированная форма `%{"type" => tag, "fields" => поля}`;
  - `{"tag", key: value}` — тегированная форма, дискриминатор `key` внутри `fields`;
  - `[key: value]` — дискриминатор `key` среди полей, без обёртки.
- `CompileError` с именем плагина и варианта: формы `"tag"`/`{"tag", …}` и `[…]` в одном плагине; повтор адреса;
  общий тег у вариантов без дискриминатора или вперемешку с `"tag"`; разные ключи дискриминатора у одного тега
  (в форме `[…]` — во всём плагине); дискриминатор не из одной пары `key: value`; wire-ключ поля спеки, равный ключу
  дискриминатора; поле struct с именем дискриминатора, чьё значение по умолчанию не равно `value`.
- Поле struct с именем дискриминатора в спеку не входит (сверка ключей его исключает); struct без такого поля
  допустим.
- `{Mod, адрес}` без спеки — ручной вариант: поля пишет автор колбэками `dump_variant(struct, codec) :: map()` и
  `load_variant(Mod, map, codec) :: {:ok, struct()} | {:error, Error.t()}` — optional `@callback` плагина,
  публичные, `@impl true`. Ручной вариант без клаузы `dump_variant/2` (при `loadable: true` — `load_variant/3`) —
  `CompileError`.

Поведение:

- `dump(%Variant{}, codec)` — сразу в форме адреса: поля по спеке (или `dump_variant/2`), дискриминатор — значение
  как объявлено (атом — атомом, как `enum:`), обёртка — по форме адреса. Ключи тегированной формы — общие с
  `Core.Codec.Redump` (одно место определения).
- `load(Variant, wire, codec)` принимает ту же форму, что отдаёт `dump`: сверяет адрес (тег и дискриминатор
  сравниваются по строке — из jsonb приходит строка) и грузит поля; `load(T, dump(x)) == {:ok, x}` для любого
  варианта.
- `load(Family, wire, codec)` принимает любой term: выбирает вариант по адресу и грузит поля. Поле struct с именем
  дискриминатора получает значение по умолчанию.
- Ошибки — `%Error{kind: :domain, ns: :codec}` с константным русским `message`:
  - `:invalid_value` — повреждённая форма: не map, нет тега-строки, `fields` не map, нет дискриминатора;
  - `:unknown_tag` — адрес вне семейства или (у `load(Variant, …)`) не этого варианта;
    `detail: %{tag: тег | nil, discriminator: значение | nil}`.
- `type(struct | module) :: String.t()` — тег тегированной формы, у формы `[…]` — значение дискриминатора строкой;
  `types() :: MapSet.t(String.t())`. `mod_by_tag/1` не генерируется.
- `__codec_variants__/0` с `@doc false` — `[{module(), адрес, спека | :manual}]`: опора для выведенной
  redump-спеки (`11-derived-redump.md`).
- Ручная клауза `dump/2` / `load/3` на вариант или на семейство — `CompileError` «never match», как на тип из
  `fields:`. Запрет `@spec` у `dump/2` / `load/3` распространяется на плагин с `variants:`.
- Сгенерированные клаузы соблюдают ADR-0014: голова закрывает struct варианта паттерном, результат сужен до
  `{:ok, %Variant{}} | {:error, _}` (у семейства — до объединения вариантов), код сужения — `generated: true`.
- Существующие плагины с `fields:` в библиотеке, тестах, фикстуре-потребителе и примерах норм убирают типы спеки из
  `types:`; пример `union:` в `docs/rules/11-domain.md` переходит на `variants:`.

Обезличенный пример для нормы:

```elixir
use Core.Codec.Plugin,
  union: Shape,
  variants: [
    {Shape.Circle, "circle", radius: [type: :pos_integer]},
    {Shape.Square, "square", side: [type: :pos_integer]},
    {Shape.Rect, {"polygon", kind: :rect}, width: [type: :pos_integer], height: [type: :pos_integer]},
    {Shape.Triangle, {"polygon", kind: :triangle}, sides: [list: [type: :pos_integer]]}
  ]
```

**Key interfaces:**
- опции `Core.Codec.Plugin`: новая `variants:`; `types:` — только ручные, необязательный; `__codec_types__/0` —
  объединение; проверка покрытия и «never match» учитывают варианты и семейство;
- optional `@callback` `dump_variant/2`, `load_variant/3`;
- генерируемые `type/1`, `types/0`, `__codec_variants__/0`;
- коды ошибок `:invalid_value`, `:unknown_tag` в `ns: :codec`;
- `Core.Codec.Redump`: ключи тегированной формы — из того же места, что у плагина.

**Acceptance criteria:**
- [ ] Плагин только с `fields:` и без `types:` компилируется; `__codec_types__/0` — ключи спеки.
- [ ] Тип в двух из `types:` / `fields:` / `variants:` — `CompileError` с именем плагина и типа; плагин без типов —
      `CompileError`; `variants:` без `union:` — `CompileError`.
- [ ] Для каждой формы адреса: `dump` даёт ожидаемую wire-map (литерал в тесте), round-trip `load(Family, dump(x))`
      и `load(Variant, dump(x))` через тестовый фасад даёт `{:ok, x}`; загрузка wire со строковыми и атомарными
      ключами и дискриминатором-строкой проходит.
- [ ] Общий тег с дискриминатором: варианты различаются при загрузке по семейству; поле struct дискриминатора
      восстановлено значением по умолчанию.
- [ ] Каждое `CompileError` из раздела «Объявление» покрыто тестом с проверкой текста.
- [ ] Ручной вариант `{Mod, адрес}`: тег, обёртку и выбор делает библиотека, поля — `dump_variant/2` /
