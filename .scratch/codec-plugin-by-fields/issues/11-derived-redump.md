# 11: Redump-спека, выведенная из спеки полей и вариантов

**Status:** ready-for-agent

**Blocked by:** 08, 10.

**Проблема:** спеки `Core.Codec.Redump` пишутся руками и повторяют Prim полей, уже объявленные спекой кодека. На
2026-10-11 таких спек 15 у четырёх потребителей (A — 5, B — 6, E — 3, F — 1); у A ещё 12 объявлений `wire_prims:`
только ради redump и отдельный тест сверки read-wire с агрегатным путём. Расхождение спеки с кодеком ловит только
такой тест.

**Что известно:**

- спека полей знает Prim каждого поля: `prim:` → `{:prim, P}`, `list:` → `{:list, _}`, `enum:` / `type:` в redump не
  нужны;
- `entity:` и `union:` ссылаются на тип другого плагина — нужна ссылочная форма спеки, разрешаемая через фасад, или
  вывод при сборке только внутри плагина;
- вариант семейства — `__codec_variants__/0` (08): тегированная форма ложится на `{:tagged, _}`, дискриминатор
  внутри `fields` и форма без обёртки — нет, `Core.Codec.Redump` придётся расширить;
- `Core.Codec.Redump` отвергает sensitive-Prim, а спека полей их допускает — поле sensitive в выведенной спеке: пропуск
  или `CompileError`;
- `Core.View` ссылается на спеку `jsonb: {Mod, :fun}` — ссылка на тип (`jsonb: Type`) убрала бы функцию-обёртку у
  потребителя.

**Нужно до реализации:** форма выведенной спеки и ссылок между плагинами, расширение `{:tagged, _}` под
дискриминатор и форму без обёртки, sensitive, форма `jsonb:` во View, нужно ли ADR.

## Agent Brief

**Category:** enhancement
**Summary:** спека пере-дампа (`Core.Codec.Redump`) выводится из спеки полей у типов `fields:` / `variants:` и
семейства; ручной плагин объявляет её колбэком; ссылку на тип разрешает фасад; `Core.View` ссылается на
спеку по типу.

**Current behavior:**
Спека `Core.Codec.Redump` пишется руками функцией `<форма>_redump_spec/0` и повторяет Prim, уже
объявленные спекой полей плагина. На спеку типа другого плагина ссылаются вызовом его функции. Формы
спеки — `{:prim, Mod} | {:map, %{атом => спека}} | {:list, спека} | {:tagged, %{тег => спека}}`. Sensitive-Prim
и Prim с кастомным kind в спеке отвергает `validate!/1`, значение не из спеки проходит как есть.
`Core.View` ссылается на спеку только `jsonb: {Mod, :fun}`. Фасад отдаёт `dump/1`, `load/2`, `load!/2`,
и `Core.Codec.Facade.Behaviour` закрепляет «и больше ничего». Расхождение ручной спеки с кодеком
ловит только сверочный тест read-wire (`docs/rules/19-testing.md`, «jsonb на read-пути: контракт wire» —
MUST для любой формы).

**Desired behavior:**

Выведенная спека:

- Плагин генерирует служебную `__codec_redump__(module()) :: Core.Codec.Redump.spec()` (`@doc false`) для
  каждого типа из `fields:`, каждого варианта из `variants:` и семейства с `variants:`.
- Тип по полям даёт `{:map, %{ключ => спека}}`, где ключ — wire-ключ поля (`wire:` или имя поля). Значение
  с ключами-строками (jsonb после Postgres) и с ключами-атомами переводится одинаково. Спека поля по виду:

  | Вид поля | В спеке |
  |---|---|
  | `prim:` с приводимым kind, включая plain-kind (`:string`, `:integer`) | `{:prim, P}` |
  | `prim:` с кастомным kind | нет |
  | `prim:` sensitive (и элементом `list:`) | `:sensitive` |
  | `enum:`, `type:` | нет |
  | `entity: M`, `union: F` | `{:codec, M}` / `{:codec, F}` |
  | `list: спека` | `{:list, спека элемента}`; нет, если у элемента её нет |

- Вариант даёт спеку своих полей — без дискриминатора и обёртки. Семейство с тегированной формой даёт
  `{:tagged, %{тег => {:map, …}}}`; спеки вариантов одного тега (адрес `{"tag", key: v}`) сливаются в
  одну map. Семейство с формой без обёртки (`[key: v]`) даёт `{:map, слияние спек всех вариантов}`.
- Одноимённый wire-ключ с разной спекой у сливаемых вариантов — `CompileError` при сборке плагина;
  в тексте — плагин, варианты и ключ.

Ручная спека:

- Ручной плагин MAY объявить optional `@callback redump_spec(module()) :: Core.Codec.Redump.spec()`
  (`@impl true`, публичный). Клаузы — на ручные типы, ручные варианты `{Mod, адрес}` (спека их полей,
  слияние и обёртку делает плагин, как при выводе) и семейство `union:` без `variants:`.
- Клауза `redump_spec/1` на тип с выведенной спекой — `CompileError` «never match», как ручная клауза
  `dump/2` / `load/3` на тип из `fields:`.

Разрешение:

- Спека `Core.Codec.Redump` получает узлы `{:codec, module()}` и `:sensitive`.
- `run(value, {:codec, M}, codec)` берёт спеку у `codec.__codec_redump__(M)` и переводит по ней.
  Тотальность по значению сохраняется: `nil`, не map, неизвестный тег — как есть.
- `:sensitive` — значение поля `{:map, _}`: ключ удаляется из результата. Тотальность по значению
  сохраняется: ключа нет — ничего не делается.
- `validate!/1` принимает `{:codec, M}` с атомом `M` (существование не проверяет) и `:sensitive` только
  значением поля `{:map, _}`; иначе — `ArgumentError`. Принимает ключи, которые даёт выведенная спека.
  Прежние ручные спеки проходят без изменений.
- Фасад генерирует `__codec_redump__/1`: тип выводит или объявляет его плагин — спека; тип плагина без
  спеки (ручной без клаузы колбэка, ручной вариант без клаузы в семействе с `variants:`) и модуль без
  плагина — `ArgumentError`, где названы тип и плагин. `Core.Codec.Facade.Behaviour` получает
  `@callback __codec_redump__(module()) :: Core.Codec.Redump.spec()`; формулировка «и больше ничего»
  уточняется.

View:

- `jsonb: Type` и `list: [jsonb: Type]` в `fields:` и `forms:`: дамп — `Redump.run(value, {:codec, Type}, codec)`,
  тип — `map()` / `[map()]`, как у `jsonb: {Mod, :fun}`.
- `CompileError` с именем поля: `Type` не собранный модуль, Prim или `Core.Enum`. Есть ли у типа спека,
  сборка View не проверяет.
- `jsonb: {Mod, :fun}` не меняется.

**Key interfaces:**
- `Core.Codec.Redump.spec()` — узлы `{:codec, module()}`, `:sensitive`; `run/3`, `validate!/1`;
- генерируемая плагином `__codec_redump__/1`; optional `@callback redump_spec/1` `Core.Codec.Plugin`;
- генерируемая фасадом `__codec_redump__/1`; `@callback` `Core.Codec.Facade.Behaviour`;
- вид поля `jsonb:` у `Core.View` — модуль типа.

**Acceptance criteria:**
- [ ] Через тестовые фасады двух профилей: для типа по полям с полями всех видов
      `InCodec.dump(x) |> json_roundtrip() |> Redump.run({:codec, T}, OutCodec)` равен
      `OutCodec.dump(x) |> json_roundtrip()`; поле sensitive в результате отсутствует; `wire:` учитывается;
      `entity:`, `union:` и `list:` с ними — через `{:codec, _}`.
- [ ] То же для семейства в каждой форме адреса: `"tag"`, два варианта под одним тегом с
      дискриминатором, форма без обёртки.
- [ ] Конфликт одноимённого ключа у сливаемых вариантов — `CompileError` с проверкой текста.
- [ ] Ручной плагин с `redump_spec/1`: ручной тип, ручной вариант в семействе с `variants:` и семейство
