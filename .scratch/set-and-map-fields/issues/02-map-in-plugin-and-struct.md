# 02: `map:` в плагине по полям и структуре по полям

**What to build:** автор объявляет поле-словарь `map: [key: <спека>, value: <спека>]` и получает round-trip
через Codec-плагин по полям (wire — объект) и тип в структуре по полям; ключ без wire-строки и персональный ключ
не собираются. Спека — `.scratch/set-and-map-fields/spec.md`, решение — ADR-0091.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Спека полей принимает `map: [key:, value:]` во всех режимах; значение — любой вид.
- [ ] Ключ — Prim со строковой базой, `enum:` или `type: :string`; иное — `CompileError` «ожидается вид с
      wire-строкой, получено …»; персональный ключ (`personal: true` / `sensitive:`) — `CompileError`;
      недостающий или лишний ключ в `map: [...]` — `CompileError` с префиксом декларации и именем поля.
- [ ] Плагин по полям: `dump` — объект `{"<wire ключа>": <wire значения>}`; `load` — map по видам ключа и
      значения; не-объект, невалидный ключ или значение — `{:error, %Error{}}` с ключом в пути.
- [ ] Плагин по полям: `default: %{}` — wire-литерал отсутствующего ключа.
- [ ] Структура по полям: `@type t` — `%{optional(<ключ>) => <значение>}`; `default:` проверяется по видам ключа
      и значения.
- [ ] Сверка плагина со структурой по полям учитывает `map:` с видами ключа и значения.
- [ ] Тесты через `use`: round-trip, ошибки с путём, каждый отказ декларации, тип у модуля в `.beam`, отказы
      `default:`, расхождение со структурой.
- [ ] `@moduledoc` плагина по полям и `Core.Struct`: вид `map:`, его wire, ограничение ключа, различие с
      `type: :map`.
- [ ] CHANGELOG: пункт из 01 дополняется.
- [ ] `make` зелёный.
