внутри них проверяется на полноту подписей, как внутри `list:`. Спека — `.scratch/set-and-map-fields/spec.md`,
решение — ADR-0091.

- [x] Полнота подписей, ссылки и текст проходят элемент множества и значение словаря, как элемент `list:`.
