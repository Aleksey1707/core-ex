# 01: `set:` в плагине по полям и структуре по полям

**What to build:** автор объявляет поле-множество `set: <спека элемента>` и получает round-trip через
Codec-плагин по полям и тип в структуре по полям. Спека — `.scratch/set-and-map-fields/spec.md`, решение —
ADR-0091.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Спека полей принимает `set: <спека>` во всех режимах; элемент — любой вид, как у элемента `list:`.
- [ ] Плагин по полям: `dump` — список, отсортированный по wire элемента; `load` — `MapSet`, повторы
      схлопываются; не-список и невалидный элемент — `{:error, %Error{}}` с индексом элемента в пути.
- [ ] Плагин по полям: `default: []` — wire-литерал отсутствующего ключа.
- [ ] Структура по полям: `@type t` — `MapSet.t(<элемент>)`, `| nil` при `optional: true`; `default:`
      (`MapSet.new()`, `MapSet.new([@x])`) проверяется по виду элемента.
- [ ] Сверка плагина со структурой по полям учитывает `set:` с видом элемента.
- [ ] Генерируемая голова сужает значение паттерном (`20-agreements.md`, «Генерируемые функции»).
- [ ] Тесты через `use`: round-trip, детерминизм на значении, чей порядок обхода `MapSet` расходится с wire,
      схлопывание повторов, ошибки с путём, тип у модуля в `.beam`, отказы `default:`, расхождение со структурой.
- [ ] `@moduledoc` плагина по полям и `Core.Struct`: вид `set:` и его wire.
- [ ] CHANGELOG, «Не выпущено» → «Новое»: пункт о видах спеки полей.
- [ ] `make` зелёный.
