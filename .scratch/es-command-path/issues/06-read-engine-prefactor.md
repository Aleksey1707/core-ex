# 06: Prefactor — общий движок чтения

**What to build:** восстановление состояния, открытие хвостов, пересвёртка отвергнутого снапшота, свёртка и сверка версии живут в одном движке чтения, а не в теле общего прогона. Поведение не меняется: те же исходы, те же снапшоты, те же теги telemetry, публичные функции репозитория не трогаются.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Движок чтения владеет восстановлением, хвостами, пересвёрткой, свёрткой и сверкой версии.
- [ ] Прогон чтения использует движок; командные и read-model операции дают прежние результаты.
- [ ] Политика снапшотов, теги telemetry `:get_decision`/`:refresh` и измерения загрузки не изменились.
- [ ] Публичные функции репозитория и их поведение не изменились.
- [ ] Тесты чтения, снапшотов и ADR-0016 зелёные без правок сценариев.
