# 01: `Transact`: один вход и `dao:`

**What to build:** у транзакции команды остаётся один публичный вход: потребитель учит `run/2`, библиотека — внутренний счётчик повторов; схема `retries:` и описание опций живут в одном месте. Команду можно провести на явно заданном `dao`, и guard «не внутри транзакции» проверяет именно его.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] `run/2` — единственный публичный вход; `run_counted/2` помечен внутренним и не виден в документации.
- [ ] Схема `retries:` и блок описания опций объявлены один раз, без второго экземпляра.
- [ ] `dao:` принимается обоими входами; умолчание — `Core.Config.dao/0`, прочитанное в рантайме вызова.
- [ ] Повтор после отказа хранилища идёт на разрешённом `dao:`.
- [ ] Вызов внутри открытой транзакции даёт `ArgumentError`, проверка смотрит на тот же `dao:`.
- [ ] Тесты повтора, исчерпания и запрета внутри транзакции зелёные; CHANGELOG не меняется — изменение внутреннее.
