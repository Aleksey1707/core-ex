# 07: Командное чтение — свой interface

**What to build:** у чтения команды свой узкий interface: голова и хвост, правило «явная версия на пустом потоке» (ADR-0016) и снапшоты командных операций. Заявка read-model операций больше не несёт командные поля, а команда — неиспользуемые поля read-model.

**Blocked by:** 06 — общий движок чтения как implementation.

**Status:** ready-for-agent

- [ ] Командное чтение идёт через свой interface: голова с решением и дочитка хвоста.
- [ ] Правило ADR-0016 (явная версия на пустом потоке) живёт и проверяется в одном месте.
- [ ] `Load.Request` описывает только read-model операции; командные поля `born?`, `decide`, `version`/`pairs` в нём отсутствуют.
- [ ] Снапшоты командных операций пишутся по прежней политике; теги telemetry `:get_decision` и `:refresh` сохранены.
- [ ] Публичные колбэки репозитория и их результаты не изменились.
- [ ] Тесты чтения, снапшотов, `get_at`/`get_many_at` и ADR-0016 зелёные; CHANGELOG не меняется — изменение внутреннее.
