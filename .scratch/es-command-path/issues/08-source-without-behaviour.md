# 08: Источник строк без behaviour

**What to build:** behaviour с единственным боевым адаптером исчезает: движок чтения берёт источник строк из конфигурации репозитория, а заявка чтения поля `source` больше не несёт. Тестовый источник строк остаётся обычным module и внедряется через конфигурацию, поэтому тесты движка по-прежнему идут без БД.

**Blocked by:** 07 — заявка чтения уже разделена на командную и read-model.

**Status:** resolved

- [x] Behaviour источника строк удалён; движок зовёт выборку строк у module из конфигурации.
- [x] `Load.Request` не содержит поля `source`; `Config.source` остаётся внутренним seam и по умолчанию указывает на реализацию репозитория.
- [x] Тестовый источник строк — обычный module с выборкой строк и признаком «снапшоты не пишет», без behaviour.
- [x] Тип строки переехал из удалённого behaviour в движок чтения; спецификации и диалайзер чистые.
- [x] Тесты движка внедряют источник через конфигурацию и не ходят в БД.
- [x] Поведение чтения, снапшотов и теги telemetry не изменились; CHANGELOG не меняется — изменение внутреннее.
