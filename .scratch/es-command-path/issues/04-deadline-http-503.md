# 04: Дедлайн на HTTP-границе — 503, не 500

**What to build:** ошибка дедлайна команды доходит до клиента как 503 с константным текстом и уровнем лога `:warning`; служба учёта ошибок не получает событие, шаблон 500 и текст прикладной ошибки наружу не уходят.

**Blocked by:** 03 — ошибка `%Error{code: :deadline_exceeded}` должна существовать.

- [ ] Уровень лога — `:warning`; CriticalError не зовётся.
