# 14: `Opts.validate!` — одна ошибка с обоими списками

**What to build:** автор `use Core.*`, передавший старую форму опций, получает один `CompileError`, где рядом стоят
недостающие и неизвестные опции: `<label>: нет обязательных опций: [:family]; неизвестные опции: [:event]`. Если
непуст один список, текст прежний. Переименованная опция видна рядом с заменой без отдельного механизма. Спека —
`../spec.md`, «`Core.Helper.Opts.validate!`», «Порядок работ», срез 1; ADR-0084; решение — тикет 10 карты.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Недостающие и неизвестные опции собираются до `raise`, ошибка одна; при одном непустом списке текст прежний.
- [ ] `require!` (открытый список опций) не изменён.
- [ ] Тест `Core.Helper.Opts`: оба списка в одном сообщении; по одному списку — прежние тексты.
- [ ] CHANGELOG не трогается: внутренняя правка.
- [ ] Приёмка: `make` целиком.
