# 06: Модуль-оглавление контекста

**What to build:** у каждого bounded context потребителя есть точка входа `MyApp.Domain.<BC>` —
модуль рядом с каталогом контекста, чей `@moduledoc` даёт карту контекста. Линтер требует его
наличие.

**Blocked by:** 01

**Status:** done

**Spec:** [Раскладка потребителя](../spec.md) — «Свод потребителя», «Линтер `boundary_lint --consumer`»

- [x] `app/10`, «Раскладка»: наличие модуля-оглавления — `MUST`; содержание (назначение, агрегаты,
      срезы, read-модели, компоненты, ссылки на другие контексты) — `SHOULD`, с примером.
- [x] Оглавление лежит на уровне `domain/`, а не в корне контекста — правило «модулей в корне
      контекста нет» не нарушается; свод говорит это явно.
- [x] Линтер: каталог `domain/<bc>/` без модуля `MyApp.Domain.<BC>` — нарушение; содержание не
      проверяется.
- [x] Тесты линтера: контекст без оглавления, контекст с оглавлением, маркер-исключение.
