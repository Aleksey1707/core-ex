# 13: порты чтения над несколькими агрегатами

**Status:** needs-triage

**Найдено:** аудит раскладки, итерация 2 (2026-09-28).

## Факты

- У потребителя C есть порты чтения на пути команды (каталог объектов для импорта), источники для
  нескольких read-моделей (`Source`), read-репозитории срезов над таблицами агрегата
  (`app/13`: MUST «в каталоге агрегата» против MAY «в срез со своей формой»), карточка — строка
  одного агрегата из семейства из шести.
- У потребителя B есть read-репозиторий без View в `Common` (скаляр и проверка существования).

## Предложение

- Место `<scope>/<name>/source{,/pg}.ex` (или имя `ReadRepo`) для порта, который читает несколько
  агрегатов на пути команды или питает несколько read-моделей.
- Приоритет правил «чтение state-stored агрегата — в его каталоге» против «своя форма — в срез».
- Семейство агрегатов: `Common.<Family>.<ReadModel>`.

Решать при адаптации потребителей C и B.
