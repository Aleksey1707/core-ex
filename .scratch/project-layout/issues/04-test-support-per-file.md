# 04: Фикстуры `test/support`: событие и команда — по файлу

**What to build:** фикстуры библиотеки, с которых копируют потребителя, перестают нарушать
`MUST` «событие и команда — каждое в своём файле»: события и команды вынесены из семейств и из
модулей агрегатов в отдельные файлы.

**Blocked by:** None (can start immediately)

**Status:** done

**Spec:** [Раскладка потребителя](../spec.md) — «Фикстуры»

- [x] Фикстура event-sourced агрегатов: каждое событие и каждая команда — отдельный файл;
      семейства держат только `@moduledoc` и `@type t`.
- [x] Фикстура событий общего назначения: события — по файлу.
- [x] Имена модулей, wire-теги и golden-фикстуры не меняются.
- [x] Путь каждого нового файла совпадает с именем модуля.
- [x] Изменение внутреннее — в CHANGELOG не попадает.
- [x] `make` зелёный.
