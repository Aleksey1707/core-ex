# 09: Компонент и его корень в `app/17`

**What to build:** свод описывает компонент — процессы с одним тумблером под одним
`<Component>.Supervisor`, который сам владеет тумблером, опциями, проверками старта и
`watch_list/0`. `Application` перечисляет корни компонентов плоско, подписчики брокера строятся
библиотечным деревом.

**Blocked by:** 01, 03

**Status:** done

**Spec:** [Раскладка потребителя](../spec.md) — «Свод потребителя»; ADR-0024
