# 07: Read-модель как единица раскладки

**What to build:** свод раскладывает чтение по read-моделям, а не по агрегатам: View, ReadRepo и
проекция лежат в одном каталоге, проекция заводится на каждую read-модель и пишет свои таблицы
сама. Примеры свода библиотеки и README переходят на `Common` по умолчанию.

**Blocked by:** 01

**Status:** ready-for-agent

**Spec:** [Раскладка потребителя](../spec.md) — «Свод потребителя», «Свод библиотеки, README, CONTEXT»

      чтение state-stored агрегата из своей таблицы — в каталоге агрегата.
