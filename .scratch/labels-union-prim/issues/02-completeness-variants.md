# 02: Ратчет полноты — варианты семейства и решения

**What to build:** ратчет полноты приложения (`Core.Labels.CompletenessCase`) проверяет видимое поле
`union:` по вариантам: Prim-вариант — как Prim (вид id), вариант-struct — как struct (объявление полей),
скрытое поле не проверяется. Корректное семейство Prim-вариантов проходит все проверки и не даёт ложного
пробела «struct без решения по полям». Prim-вариант без вида (`Kind.of/1` — `:unkinded`) и с custom-видом
(`{:custom, _}`) — пробел вида id с владельцем, полем и модулем. Вариант-struct без объявления полей —
пробел полей; семейство без плагина — прежний пробел неизвестного семейства. Событие с видимым полем
семейства входит в полный набор ратчета; таблица «вид × подписи × ссылки × полнота» расширена. Решение
зафиксировано ADR-0098, влияние — в CHANGELOG (в том же коммите, по правилу репозитория).

**Blocked by:** 01 — общая фикстура семейства Prim-вариантов.
