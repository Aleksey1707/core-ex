# 02: Раскладка контекста по всему своду

**What to build:** свод библиотеки и ярус потребителя описывают вертикаль целиком: read-модель агрегата и по
назначению, подкаталог актора со своим ReadRepo и View, `values/`, `errors.ex`, операцию над равноправными агрегатами,
запись двух контекстов и join между контекстами. Примеров с `Common` и срезами в своде, README и документации модулей
не остаётся.

**Blocked by:** 01

**Status:** ready-for-agent

**Spec:** [Контекст — граница Boundary, раскладка — вертикаль по агрегату](../spec.md) — «Раскладка», «Направления»,
«Объявления контекста»

- [ ] `app/10`, «Usecases»: имя модуля — `<Aggregate>.<Actor>.Usecases`, общее чтение — `<Aggregate>.Usecases`;
      операция над равноправными агрегатами — `<Operation>.<Actor>.Usecases` (Q25); запись двух контекстов — MUST NOT,
      вторая запись — задача второго контекста в той же транзакции или реакция (Q26); хелпер `Query` — в каталоге
      агрегата
- [ ] `app/11`: значение без владельца — `values/`; реестр плагинов — из объявлений контекстов (Q4)
- [ ] `app/12`: места каталогов ошибок — каталог агрегата и `errors.ex` контекста
- [ ] `app/13`: деревья без `common/`; read-модель агрегата — в его каталоге, не по агрегату — каталог по назначению;
      ReadRepo актора — в подкаталоге актора со своими specs; join — MAY внутри контекста, MUST NOT между контекстами
      (Q30)
