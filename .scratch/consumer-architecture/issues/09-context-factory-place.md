# 09: `ContextFactory` — место в границах

**What to build:** решение, в какой границе живёт `MyApp.ContextFactory`. После тикетов 01 и 03 `MyApp` границей не
является, а строка таблицы namespaces (`app/10`, «Top-level namespaces») оставляет модуль верхнего уровня
`lib/my_app/context_factory.ex` — вне границ, хотя «каждый модуль `lib/` MUST принадлежать границе». Своя
граница-подсистема даёт цикл с контекстом учётной записи: его воркеры берут актора у фабрики, а фабрика зовёт
аксессор `CurrentUser` этого контекста. У потребителя A решение Q18 — экспорт контекста учётной записи рядом с
аксессором; для потребителя без агрегата учётной записи аксессор живёт в подсистеме `MyApp.Auth` (`app/11`,
«Context»).
