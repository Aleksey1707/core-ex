который каждый потребитель пишет сам. Если нужно — его опции и место корня `MyAppApp.Outbox` после него.

**Status:** done

## Факты

Обзор — `research/03-component-roots.md`, «Корень очереди у пяти потребителей»:

- корень очереди есть у всех пяти потребителей с компонентами: один состав детей в одном порядке и одни ключи
  `Core.Outbox` в опциях, 31–63 строки опций на корень;
- `rest_for_one` по порядку детей — `MUST` свода (`docs/rules/17-otp-concurrency.md`, «Дерево процессов»; очередь —
  пример в `app/17`, «Дерево процессов»), проверка единственности — `MUST` в корне очереди (`app/14`,
  «Единственность поллера»), её вызов держит ратчет;
- деревья библиотеки config и env не читают: опции собирает приложение, как у
  `Core.Es.Projection.Supervisor` (`app/17`, «Готовое дерево без корня»).
