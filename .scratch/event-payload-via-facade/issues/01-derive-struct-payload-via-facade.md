# 01: Вывод нагрузки-struct через фасад и проверка фасада

**What to build:** событие, чья нагрузка — сущность со своим Codec-плагином, кодируется без клауз в
`<Aggregate>.Event.Codec`: кодек событий выводит передачу фасаду целиком, как у нагрузки-Prim. Тип нагрузки, который
не обслуживает ни один плагин фасада, — `CompileError` при сборке фасада. Спека — `../spec.md`, разделы «Вывод
нагрузки через фасад», «Проверка в фасаде», «Документы».

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Нагрузка-struct (не по полям, не `Es.ValueChanged`, не Prim) — четвёртый случай вывода: в конверте —
      `codec.dump(сущность)`, загрузка — `codec.load(Payload, wire)`; round-trip через JSON по модулю события и по
      семейству; ошибка плагина сущности — `{:error, %Error{}}` загрузки события.
- [x] Ручная клауза для такого события — существующий `CompileError` «never match».
- [x] Сборка фасада: нагрузка-struct события из `tags:` кодека событий среди плагинов, которой нет в
      `__codec_types__` ни одного плагина того же фасада, — `CompileError` с типом нагрузки и кодеком событий.
- [x] Нагрузка по полям, Prim, `Es.ValueChanged` и событие без нагрузки — существующие тесты без правки.
- [x] Фикстура-потребитель и `test/support`: клаузы передачи фасаду удалены; `make consumer-check` зелёный, сужение
      результата `InCodec.load` события по struct нагрузки сохранено.
- [x] ADR-0060 «Нагрузку события кодирует плагин её типа»: замер, отвергнутые варианты (явный список событий в
      `use`, `payload: {:codec, M}` в `use Es.Event`, переходный период с предупреждением), решение целиком —
      включая удаление колбэков из тикета 02, цена.
- [x] `docs/rules/11-domain.md`: четвёртый случай выводимых клауз нагрузки; `docs/rules/app/11-domain.md`: образец
      нагрузки-сущности без клауз.
- [x] CHANGELOG: дополнен существующий пункт «Не выпущено» о выводе клауз нагрузки (было — клаузы передачи фасаду,
      стало — ничего; новый `CompileError` фасада).
- [x] `make` зелёный.

## Comments

Реализован одним коммитом с 02: после вывода каждой struct-нагрузки любая ручная клауза мертва, и без 02 фикстуры и тесты не собирались. Ручная клауза — сразу новый `CompileError` из 02, а не «never match».
