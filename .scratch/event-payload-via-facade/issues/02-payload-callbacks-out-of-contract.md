# 02: Колбэки нагрузки уходят из контракта

**What to build:** у кодека событий не остаётся способа закодировать нагрузку самому: `dump_payload/2` и
`load_payload/3` удалены из behaviour `Core.Es.Event.Codec`, их определение в модуле кодека — `CompileError`, который
называет функцию и говорит перенести форму нагрузки в плагин её типа (или объявить нагрузку по полям). Нестандартная
wire-форма нагрузки живёт в ручном плагине её типа. Спека — `../spec.md`, «Вывод нагрузки через фасад» и
«Документы»; решение — ADR-0060.

**Blocked by:** 01.

**Status:** resolved

- [x] `dump_payload/2` / `load_payload/3` удалены из `@callback` и `@optional_callbacks`; выведенные клаузы —
      внутренние функции кодека; `upcast/2` без изменений.
- [x] Определение `dump_payload/2` или `load_payload/3` в модуле `use Core.Es.Event.Codec` — `CompileError` с
      подсказкой; прежние «never match» для ручной клаузы и запрет `@spec` у этих функций поглощены новой ошибкой.
- [x] Проверки ручных клауз, потерявшие предмет (событие с нагрузкой без клаузы, клауза с нагрузкой другого
      события), удалены вместе с тестами на них.
- [x] Тест: нестандартная форма нагрузки ручным плагином её типа — round-trip через фасад, конверт тот же, что у
      прежней ручной клаузы.
- [x] Фикстура-потребитель: сценарии `# expect:` о ручной клаузе выводимой нагрузки переведены на новый
      `CompileError` или сняты; ручные нагрузки фикстуры — в плагинах; `make consumer-check` зелёный.
- [x] `docs/rules/14-events-outbox.md`: состав `use Core.Es.Event.Codec` (колбэк — только `upcast/2`), перечень
      ошибок сборки, «формат нагрузки задаёт плагин её типа»; `docs/rules/app/11-domain.md`: нестандартная форма —
      ручной плагин в `<Aggregate>.Codec`.
- [x] CHANGELOG, «Ломающие изменения контракта»: было — ручные `dump_payload/2` / `load_payload/3`, стало — ручной
      плагин типа нагрузки (пример); правка `app/**` — тем же коммитом.
- [x] `make` зелёный.
