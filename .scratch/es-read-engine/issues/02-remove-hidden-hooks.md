# 02: Убрать скрытые хуки чтения

**What to build:** у write-репозитория event-sourced агрегата больше нет генерируемых
`__es_get_at__`/`__es_get_many_at__`, а внутренняя загрузка не торчит публичной `@doc false`-функцией:
read-репозиторий зовёт движок напрямую. Тесты, которые держались за эти хуки, переезжают на движок и
на публичный контракт. Поведение чтения не меняется. Спека — `.scratch/es-read-engine/spec.md`.

**Blocked by:** A1 (`01-load-engine-extract`).

**Status:** resolved

- [x] Read-репозиторий получает состояние на версии через движок, а не через сгенерированные функции write-репозитория.
- [x] Из write-репозитория удалены генерируемые хуки чтения; публичной функции загрузки со спекой потоков больше нет.
- [x] Тесты, звавшие хуки или публичную загрузку, переведены на движок; тестов «хука нет» не заводится — отсутствие видно компиляцией фикстур.
- [x] Чтение на версии и обычное чтение дают прежние исходы, ошибки и телеметрию; `make` зелёный.
- [x] CHANGELOG, «Изменения контракта макросов»: хуки исчезли, поведение write-репозитория не изменилось, потребителю править нечего.
