# 02: Печать состава и тексты для клиента

**What to build:** состав множества виден в логе и на bang-границе, а для клиента из ошибки
достаётся список текстов. Обход причин при этом множества не касается.

**Blocked by:** 01

**Status:** ready-for-agent

**Spec:** [Множество ошибок](../spec.md) — «Обход и печать»

- [x] `format_chain/1`: узел с непустым `errors` печатается как `"outer (e1 | e2)"`, рекурсивно
      по цепочке; у ошибки с пустым `errors` вывод не меняется.
- [x] `Error.messages/1` → `[String.t()]`: контейнер — `to_string/1` каждого элемента в порядке
      состава; обычная ошибка — `[to_string(error)]`.
- [x] `Exc.message/1`: контейнер — `format_chain/1`, обычная ошибка — прежний `to_string/1`.
- [x] `has?/2`, `find/2`, `chain/1`, `root/1`, `unwrap/1` и `Enumerable` не меняются: читают
      только цепочку причин. Тест закрепляет это явно — `has?` по коду элемента множества даёт
      `false`, `Enum.count/1` считает цепочку.
- [x] `@moduledoc` `Core.Error` называет границу обхода и отсылает к ADR-0021.
- [x] Тесты: печать контейнера в цепочке и без неё, `messages/1` на обоих видах, текст `Exc`,
      негативные тесты обхода.
