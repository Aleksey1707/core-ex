# 02: Core.Struct — типы чтения/записи, типизированный default:, Inspect

**What to build:** структура по полям переходит на общий IR и порождает два типа: `t()` чтения
(включает `%Destroyed{}` на ПДн-местах) и `write_t()` записи (без `%Destroyed{}`). `personal: true`
у Prim или поля автоматически делает место ПДн-местом и расширяет тип чтения; отдельный
`destroyable:` удаляется. `default:` становится одним типизированным доменным значением: struct
использует его как значение поля, Codec подставляет при отсутствующем wire-ключе; явный `null`
`default:` не заменяет. `wire:` допустим в структуре (используется Codec). `Inspect` скрывает
каждое ПДн-место, а не весь содержащий его список.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Структура с `personal:`-полем порождает `t()` с `| Core.Es.Personal.Destroyed.t()` на этом месте и `write_t()` без него; без ПДн-мест типы совпадают.
- [ ] `personal: true` у Prim делает каждое место с этим Prim ПДн-местом; `destroyable:` как отдельная опция удалён и даёт `CompileError`.
- [ ] `default:` — одно типизированное значение; `optional: true, default: nil` допустимо; явный `null` не заменяется default (optional → nil, обязательное поле → ошибка загрузки).
- [ ] `wire:` допустим в декларации структуры; расхождение wire-ключей по-прежнему `CompileError`.
- [ ] `Inspect` структуры скрывает ПДн-места, оставляя открытые поля видимыми; составное поле с `personal: true` скрывается целиком.
- [ ] Тесты структуры по полям обновлены под новые типы и `default:`; `consumer-check` не растит храповик вывода типов.
