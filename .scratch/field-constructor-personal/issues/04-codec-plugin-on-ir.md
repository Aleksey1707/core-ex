# 04: Core.Codec.Plugin на общей декларации

**What to build:** Codec-плагин регистрирует типы (`types:`) и читает их общую декларацию
`__core_fields__`, а не объявляет поля повторно. Декларативный тип получает сгенерированные
`dump/2`/`load/3` и redump-спеку; тип без декларации требует ручные клаузы; `Core.Union` получает
семейную загрузку по адресу автоматически. `fields:`/`variants:` как способ объявить поля/адреса
удаляются. Смешанный плагин (часть типов декларативные, часть ручные) допустим; `loadable: false`
и запрет ручной клаузы на декларативный тип сохраняются.

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] `use Core.Codec.Plugin, types:` читает `__core_fields__` декларативных типов и порождает dump/load; поля не объявляются в плагине повторно.
- [ ] Тип без декларации требует ручные `dump/2`/`load/3`; ручная клауза на декларативный тип — `CompileError` «never match».
- [ ] `Core.Union`-тип получает семейную загрузку по адресу автоматически; `fields:`/`variants:` как опции объявления удалены.
- [ ] Redump-спека выводится из общей декларации; ручные типы объявляют её как раньше.
- [ ] Round-trip через фасад по всем видам, включая `union:` с Prim-вариантами и вариантами с ручным Codec, проходит; `loadable: false` даёт только dump.
