# 08: Уничтоженное значение, субъекты и эскалация границы

**What to build:** загрузка уничтоженного ПДн и полная защита записи. `{"$pd": nil}` на ПДн-месте
даёт `%Destroyed{}` до разбора вида/варианта (для `union:`-поля с `personal: true` — до выбора
варианта, ручной Codec не вызывается); вне ПДн-места — `:invalid_value`; `{"$pd": "<строка>"}` —
`:sealed_personal_value`; `null` необязательного ПДн-поля — `nil`. Резолв субъекта и гарды:
непустое ПДн при `nil` субъекта — отказ записи, обязательное ПДн при необязательном субъекте —
`CompileError`. Эскалация границы: ПДн-лист в `set:`/ключе `map:` шифрует контейнер целиком,
`%Destroyed{}` в типе чтения — на месте контейнера. Непрозрачный тип требует `personal: true/false`.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] Уничтожение ключа субъекта даёт `%Destroyed{}` на каждом вложенном ПДн-месте; открытая часть (маршрут/статусы) читается; ни одно событие не становится нечитаемым.
- [ ] `{"$pd": nil}` вне ПДн-места — `:invalid_value`; `{"$pd": "<строка>"}` — `:sealed_personal_value`; `null` optional-ПДн — `nil`.
- [ ] Для `union:`-поля с `personal: true` уничтоженное значение возвращается до выбора варианта; адрес варианта не требуется.
- [ ] Непустое ПДн при `nil` субъекта отвергается `new/N` и guard `dump`; обязательное ПДн при необязательном субъекте — `CompileError`; субъект — UUID-Prim, открытый, сам не ПДн.
- [ ] `set:` с ПДн-элементами и `map:` с ПДн-ключом шифруются целиком; `%Destroyed{}` в типе чтения на месте контейнера; элементы не схлопываются.
- [ ] Непрозрачный тип без `personal: true` требует `personal: false`; `personal: false` не понижает `personal: true` у известных Prim/полей.
- [ ] State-stored строка хранит `%Destroyed{}` как `{"$pd": null}` и загружает без обращения к хранилищу ключей; новый event с уже уничтоженным ПДн запрещён.
