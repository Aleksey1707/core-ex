# 06: Core.View и Core.Labels.Fields на IR

**What to build:** View и подписи переходят на чтение общей декларации полей через единый IR и
интроспекцию, вместо независимого разбора. Поведение View не меняется: голые значения, свои виды
(`view`/`form`/`jsonb`), keyword `new/1`, тотальный dump. `Core.View` не принимает
`personal:`/`subject:` и не расширяет типы `%Destroyed{}`. Подписи читают общие поля и метаданные;
рекурсивная обработка уничтоженных значений в сведениях — отдельный тикет read-пути.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] `Core.View` читает общую декларацию/IR; `new/1`, дамп и wire-форма не меняются; `personal:`/`subject:` в View — `CompileError`.
- [ ] `Core.Labels.Fields` берёт поля из общей интроспекции, а не из ролевых атрибутов; повторная спека для декларативного типа по-прежнему запрещена.
- [ ] View не порождает `%Destroyed{}` в своём типе; уничтоженное значение преобразует проекция.
- [ ] Существующие тесты View и подписей проходят без смысловых правок; `consumer-check` не растит храповик.
