# 02: План чтения и источник строк

**What to build:** границы потоков и выбор снапшота считает план чтения; маркер снапшота считается
один раз за чтение; источник строк — behaviour с SQL-адаптером и тестовым, который получает готовый
план вместо повторения SQL-фильтра; расшифрованный снапшот возвращается вместе со своим потоком.
Поведение снапшотов, расшифровки ПДн и записи после чтения не меняется.

**Blocked by:** 01 (заявка на чтение — структура и один вход).

**Status:** ready-for-agent

- [ ] План чтения содержит маркер, признак расшифровки, порог и флаг записи снапшотов, а каждый поток — свой адрес, нижнюю границу, потолок, границу снапшота и признак разрешённого снапшота.
- [ ] Маркер считается один раз за чтение: SQL-запрос, адреса расшифровки и запись снапшота берут его из плана.
- [ ] Источник строк — behaviour; SQL-адаптер и тестовый источник реализуют один коллбэк и не пересчитывают границы потоков.
- [ ] Тестовый источник реализует behaviour и не содержит копии SQL-фильтра (границы снапшота, потолок версии, выбор последнего снапшота).
- [ ] Расшифрованный снапшот приходит вместе со своим потоком; склейка по позиции в общем списке исходов не нужна.
- [ ] Снапшоты: запись после чтения по порогу, расшифровка, уничтоженный ключ субъекта и зависимость маркера от настройки расшифровки — прежнее поведение.
- [ ] Свёртка без Postgres: границы версий, выбор снапшота, отвергнутый снапшот и повторное чтение, свёртка пакета версий — покрыты тестом через тестовый источник.
- [ ] `make` зелёный.
