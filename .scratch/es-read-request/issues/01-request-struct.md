# 01: Заявка на чтение — структура и один вход

**What to build:** чтение агрегата собирает заявку через конструктор операции, а не map'ой руками;
read-репозиторий получает конфигурацию чтения функцией макроса; у версионного чтения остаётся один
вход — read-репозиторий. Исходы, коды ошибок и телеметрия не меняются.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Все точки входа репозитория агрегата и read-репозитория собирают заявку конструктором операции; имена операций (`get`, `get_decision`, `get_many`, `refresh`, `get_at`, `get_many_at`) и метка `op:` в телеметрии прежние.
- [x] Флаг «можно писать снапшоты» назван по смыслу и не путается с «снапшоты включены».
- [x] Read-репозиторий получает конфигурацию чтения функцией write-репозитория и проверяет её наличие на компиляции; интроспекция persisted-атрибута и общий служебный `fetch/3` как публичная точка уходят.
- [x] Версионные функции репозитория агрегата, не вызываемые из библиотеки, удалены; публичный шов чтения на версии — read-репозиторий.
- [x] Тесты головы, пачки, решения, обновления и чтения на версии зелёные; телеметрия чтения и свёртки прежняя.
- [x] `make` зелёный.
