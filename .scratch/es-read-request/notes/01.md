# 01 — заметки для тикета 02

## Заявка

`Core.Es.Aggregate.Load.Request` (`lib/core/es/aggregate/load/request.ex`), `@moduledoc false`.
Поля: `op`, `opts`, `source`, `write_snapshots?`, `states`, `state`, `pairs`, `version`, `born?`,
`many?`, `decide`; `@enforce_keys [:op, :opts]`.

Конструкторы по операциям: `get/5`, `get_decision/6`, `get_many/4`, `refresh/5`, `get_at/5`,
`get_many_at/4`. Пятый/последний аргумент — источник строк, `nil` → `cfg.source`. Конструкторы
ставят `op`, `states`/`state`/`pairs`/`version`, `born?`/`many?`/`decide` и флаг
`write_snapshots?` (`true` у головы, пачки, решения и `refresh`; `false` у `get_at` /
`get_many_at`). `initial_states!/2` (проверка повтора id) переехал из `Repo.Pg` сюда.

`Load.head/2`, `Load.at/2`, `Load.many_at/2`: версия и пары теперь в заявке. `at/2` матчит
`%Request{state: state, version: %Version{}}`, `many_at/2` — `%Request{pairs: pairs}`.
`decide/4` в движке проверяет `is_function(fun, 1)`, потому что ключ `decide` есть всегда.

## Источник строк

`cfg.source` — замыкание `&Core.Es.Aggregate.Repo.Pg.fetch/3`, его кладёт `es_aggregate_repo/0`
(макрос `use Core.Es.Aggregate.Repo.Pg`). `__es_read_cfg__/0` возвращает тот же cfg (с
разрешёнными `dao`/`codec`). Read-репозиторий зовёт `repo.__es_read_cfg__()` в рантайме, наличие
проверяется на компиляции через `Helper.Module.exports?/3`; persisted-атрибут `:es_read_cfg` и
`es_read_repo_cfg/0`/`resolve/2` удалены.

Важно для 02: не класть remote capture в `defstruct` default — это создало цикл xref
`Load → Request → Repo.Pg`. Сейчас в структуре `source: nil`, а `source || cfg.source` в
конструкторе. Когда замыкание заменится модулем `Source`, менять: `cfg.source` (в
`es_aggregate_repo/0`), default в конструкторах, поле `source` в заявке.

## Удалено

`Core.Es.Aggregate.Repo.Pg.get_at/5` и `get_many_at/4` (мёртвые, чтение на версии — только
read-репозиторий). `fetch/3` остаётся публичной `@doc false` точкой SQL-адаптера; read-репозиторий
её больше не зовёт.

## Тесты и фикстуры

- `test/core/es/aggregate/load_test.exs`, `repo/pg_test.exs`, `repo/pg/snapshotted_test.exs`:
  заявки собираются конструкторами; источник и `write_snapshots?` переопределяются через
  `%{request | ...}` (в load_test источник — `Rows.source/2`).
- `test/core/es/aggregate/read_repo/pg_test.exs`: новый тест «конфигурация чтения берётся
  функцией `__es_read_cfg__/0`, а не атрибутом» — модуль с одним persisted-атрибутом `:es_read_cfg`
  теперь получает `CompileError`.
- `LoadRepo.cfg/0` в тестах — `es_aggregate_repo()`, в cfg появился ключ `:source`.
