# 01: Одна таблица видов с allowlist по хосту

**What to build:** язык спеки поля получает единственную таблицу видов и объявленный allowlist для
каждого хоста — структура по полям, плагин по полям, нагрузка события, View, подписи. Отдельная таблица
видов у View исчезает; вид вне allowlist даёт `CompileError` с именем хоста. Поведение, wire-форма и
тексты существующих ошибок не меняются. Это префактор для остальных срезов. Спека —
`.scratch/view-field-ir/spec.md`.

**Blocked by:** None (can start immediately).

- [ ] Вид вне allowlist даёт `CompileError` с именем хоста и именем вида.
