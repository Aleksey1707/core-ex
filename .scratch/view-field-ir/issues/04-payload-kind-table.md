# 04: Нагрузка события на общей таблице видов

**What to build:** нагрузка события берёт виды, AST дампа и загрузки из общей таблицы и адаптеров, а не
из собственного набора switch'ей. Wire-форма события, апкаст, golden-фикстуры и редакция ПДн не
меняются; неверный вид по-прежнему даёт `CompileError` с отсылкой к нагрузке. Спека —
`.scratch/view-field-ir/spec.md`.

**Blocked by:** D3 (`03-plugin-kind-adapters`).

**Status:** resolved

- [ ] Нагрузка события использует общую таблицу видов и адаптер вида; собственных switch'ей по видам не осталось.
- [ ] Wire-форма, апкаст и загрузка прежние: golden-фикстуры и round-trip тесты проходят без обновления ожиданий.
- [ ] Редакция персональных данных и путь ошибки загрузки (`поле/индекс/ключ`) не изменились.
- [ ] Неверный вид даёт `CompileError` с именем хоста «нагрузка события».
