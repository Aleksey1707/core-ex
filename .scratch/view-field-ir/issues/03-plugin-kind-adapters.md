# 03: Плагин по полям на адаптерах вида

**What to build:** плагин кодека по полям перестаёт держать шесть параллельных switch'ей по видам:
каждый вид даёт адаптер с четырьмя операциями — шаблон сопоставления, guard, дамп, загрузка. Плагин
сохраняет себе wire-ключи, `default:`, ошибки и обход полей; нагрузка события декорирует `subject:`
поверх готового адаптера, а не переписывает switch. Round-trip и wire-форма всех видов, включая
множество и словарь, не меняются. Спека — `.scratch/view-field-ir/spec.md`.

**Blocked by:** D2 (`02-view-field-ir`).

**Status:** resolved

- [ ] Адаптер вида: четыре операции, покрывающие все виды из общей таблицы; проверка полноты адаптера — на сборке.
- [ ] Шесть switch'ей плагина заменены адаптером; второго разбора видов в плагине нет.
- [ ] `set:`/`map:` сохраняют канонический порядок и форму wire; round-trip тесты зелёные.
- [ ] `subject:` в нагрузке события декорируется поверх адаптера; поведение и ошибки прежние.
- [ ] Табличный тест «вид × операция» для плагина и нагрузки; `make` и `make consumer-check` зелёные.
