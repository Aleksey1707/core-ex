# 05: Подписи на общей таблице видов

**What to build:** подписи берут список видов из общей таблицы, а не из собственных списков: сведения о
полях, ссылки и полнота описания знают те же виды, что структура, плагин и View. Поведение подписей,
форма сведений и порядок полей не меняются; объединение трёх обходов в один walker в этот тикет не
входит. Спека — `.scratch/view-field-ir/spec.md`.

**Blocked by:** D3 (`03-plugin-kind-adapters`).

**Status:** resolved

- [ ] Сведения о полях, ссылки и полнота описания читают общий список видов и правил; собственных списков видов не осталось.
- [ ] `entity`, `union`, `list`, `set`, `map`, `type` и `text:` описываются как раньше.
- [ ] Форма сведений события в веб-слое и порядок полей не изменились; существующие тесты подписей и схемы события зелёные.
- [ ] Три обхода остаются раздельными: их объединение — вне спеки.
- [ ] `make` и `make consumer-check` зелёные; CHANGELOG не меняется.
