# 03: Перевод на схему — event sourcing

**What to build:** функции event sourcing, которые сами читают свои опции, отклоняют неизвестный
ключ и значение не того типа `ArgumentError` по схеме, а их `@doc` описывает опции из схемы. Вызов
без опций на горячем пути команды не платит за проверку.
