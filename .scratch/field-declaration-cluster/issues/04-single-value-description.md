# 04: Подписи: одно описание значения

**What to build:** сведения события и словарь ссылок становятся проекциями одного прохода описания значения: подпись, вид, значение и ссылки считаются вместе, правило вида Prim вызывается на лист один раз. Форма выхода сведений, wire события страницы событий и OpenAPI-схемы не меняются; существующие тесты сведений и словаря остаются зелёными без правки ожиданий. Подмена спеки варианта семейства (ADR-0098) и канонический порядок поля-множества и поля-словаря сохраняются. Словарь сохраняет защитный обход struct'ов без объявления полей и автора события. Термин описания значения закрепляется в `CONTEXT.md`. Модуль описания внутренний, тестируется через публичные входы сведений и словаря. Спека — `.scratch/field-declaration-cluster/spec.md`, «Тикет 04» и «Testing Decisions».
