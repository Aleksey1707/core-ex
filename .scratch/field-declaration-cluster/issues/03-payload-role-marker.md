# 03: Нагрузка: роль объявляет builder

**What to build:** builder нагрузки по полям и builder изменения «было → стало» объявляют роль нагрузки; деривация кодека событий и проверка `subject:` читают объявление, а не совпадение арности конструктора с числом полей. Структура по полям с ручным `new/N` в размер декларации кодируется своим плагином и получает проверку субъекта; однополевой View не признаётся нагрузкой по полям; вложенная в событие нагрузка по-прежнему узнаётся при сборке, когда её модуль ещё открыт. Wire событий не меняется. ADR-0097 не правится: снятие записанной цены фиксируется CHANGELOG. Спека — `.scratch/field-declaration-cluster/spec.md`, «Тикет 03» и «Testing Decisions».

**Blocked by:** None (can start immediately; параллелен 01)

**Status:** ready-for-agent

- [ ] Структура по полям с ручным `new/N` в размер декларации кодируется своим плагином; проверка `subject: :aggregate_id` не пропускается
