# 05: Метрики чтения Kafka

**What to build:** оператор потребителя видит на дашборде, насколько чтение Kafka отстаёт по
каждой партиции — по времени и в сообщениях, — и получает алерт, когда отставание растёт, смещение
сброшено на earliest или чтение и commit отказывают.

**Blocked by:** 01

**Status:** done

**Spec:** [Чтение из Kafka](../spec.md)

- [x] PromEx-плагин `Core.Mq`: отставание по времени по топику и партиции (`now` минус
      `timestamp` последнего закоммиченного сообщения), ошибки чтения и commit по топику. На
      пустом топике отставание по времени не информативно — в тексте нормы.
- [x] Отставание в сообщениях по топику и партиции: `high_wm_offset` последней пачки
      `brod_consumer` (тикет 01) минус зафиксированное смещение; только у владельца аренды
      (ADR-0033).
- [x] Счётчик сброса на earliest (`OFFSET_OUT_OF_RANGE`, тикет 01) — алерт на единичное событие
      (ADR-0029).
- [x] Серии счётчиков засеваются по правилу первого события (`21-observability.md`).
- [x] Строки рекомендованных алертов с условиями и тест `promtool` в тексте нормы.
