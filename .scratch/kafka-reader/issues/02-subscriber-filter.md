# 02: Фильтр сообщений подписчика до разбора тела

**What to build:** потребитель задаёт подписчику предикат по сообщению (заголовки, ключ, топик),
и сообщение, которое предикат отверг, коммитится как пропуск без вызова `from_message`: тело не
декодируется. Без опции подписчик ведёт себя как сейчас.

**Blocked by:** None (can start immediately)

**Status:** done

**Spec:** [Чтение из Kafka](../spec.md)

- [x] Опция `MqSubscriberReliable` (например `filter:`), проверяется при старте; по умолчанию —
      пропускать всё.
- [x] Отфильтрованное сообщение — commit и исход пропуска с отдельной причиной в telemetry и
      PromEx (отличимо от `{:skip, _}` обработчика).
- [x] Исключение внутри предиката обрабатывается как ошибка обработки (без commit), а не роняет
      подписчик.
- [x] Работает поверх любого `Mq.ReaderReliable`; тест — на тестовом читателе, без брокера.
- [x] `14-events-outbox.md` (или раздел подписчика) и `CHANGELOG.md` описывают опцию.
