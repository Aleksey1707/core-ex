# 06: Словарь ссылок страницы событий

**Status:** resolved

**Blocked by:** 05.

**What to build:** usecase страницы событий одним вызовом `Core.Labels.Refs.get/2` (события страницы и контекст)
получает словарь ссылок: текущее имя каждого id с резолвером, упомянутого на странице на любой глубине. Резолвер —
`Query` контекста-владельца с `@behaviour Core.Labels.Resolver`. Спека — `../spec.md`, «Модули домена», user
stories 38–45; ADR-0063.

- [x] `Core.Labels.Resolver`: один колбэк «список id, контекст → `Result.t(%{id => имя | nil})`», контекст
      последним.
- [x] `Refs.get/2` принимает страницу событий (`Core.Pagination.Result`), список или событие; находит id видов
      `:ref` и `:user` в struct'ах, ключах и значениях map'ы, списках, нагрузке-семействе и у автора события.
- [x] Не спускается в Prim без вида id, `Date`, `DateTime`, `Decimal`; проверка «модуль несёт вид id» — одна на
      модуль в пределах вызова.
- [x] Id группируются по резолверу; резолвер вызывается один раз на группу; без id с резолвером — `{:ok, %{}}`
      без вызовов; отказ резолвера — итог; у записи без имени — `nil`.
- [x] Тесты на фикстурных резолверах с настоящим контекстом: глубина, автор, один вызов на тип (счётчик вызовов
      резолвера), пустой обход без вызовов, отказ, имя `nil`.
- [x] Свод: механизм — `docs/rules/11-domain.md`, «Подписи»; `docs/rules/app/13-repos.md` — страница потока
      отдаёт события и словарь ссылок, словарь собирает usecase, резолвер — `Query` контекста-владельца.
- [x] `CHANGELOG.md` — дополняется пункт подсистемы подписей; правка `app/**` — тем же коммитом.
- [x] `make` зелёный.
