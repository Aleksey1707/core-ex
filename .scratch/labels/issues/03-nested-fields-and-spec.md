# 03: Вложенные struct'ы, списки, семейства и спека `fields:`

**Status:** resolved

**Blocked by:** 01, 02.

**What to build:** сведения сохраняют структуру нагрузки: вложенный struct выходит группой, список — элементами
одного вида без подписи, нагрузка-семейство — группой полей своего варианта, Prim-композит — видом базового Prim.
Struct без спеки полей — нагрузка с ручным плагином кодека, вложенный struct, вариант семейства — объявляет спеку
видимых полей `fields:` на языке плагина по полям плюс вид `text:` (захват функции арности 1). Подписи полей
по типу, без значения, отдаёт `Fields.paths/1`. Спека — `../spec.md`, «Модули домена», user stories 10–14, 33–35,
46; ADR-0063.

- [x] Первым шагом: спека `fields:` разбирается нормализатором `Core.Codec.Plugin.Fields` (служебная функция для
      подсистем библиотеки), а не копией разбора; `text:` и `list: [text: …]` подсистема разбирает сама. Поведение
      плагина по полям не меняется — его тесты зелёные без правок.
- [x] `Details.build/1`: `entity:` — `group` со сведениями вложенного struct'а; `list:` — `list` из элементов
      `%{kind, value}`; `union:` — `group` полей варианта по его `Core.Labels.Fields`; Prim-композит — вид базового
      Prim; `text:` — `text` с результатом функции.
- [x] Отказы сборки: спека поля и у нагрузки события, и в `fields:`; видимое поле без спеки; спека скрытого или
      лишнего поля; `text:` не захватом арности 1; `fields:` без `labels:`.
- [x] `Fields.paths/1`: путь поля → подпись для видимых полей типа и вложенных struct'ов в порядке объявления;
      поля элемента списка struct'ов — под путём списка; у map'ы — подпись поля; `union:` путей не даёт.
- [x] Тесты: каждый вид вложенности, вариант семейства, Prim-композит, `text:`, `paths/1`, отказы сборки.
- [x] Фикстура-потребитель: struct со спекой `fields:` и вариант семейства; `make consumer-check` зелёный.
- [x] Свод: механизм `fields:`, `text:`, `paths/1` — `docs/rules/11-domain.md`, «Подписи».
- [x] `CHANGELOG.md` — дополняется пункт подсистемы подписей.
- [x] `make` зелёный.
