# 08: Дамп сведений на wire

**Status:** resolved

**Blocked by:** 04, 05, 06.

**What to build:** модуль приложения с `use Core.Web.Labels` (внешний профиль кодека `codec:` и функция дампа
ссылки на учётную запись `user_ref: [dump:]`) получает `to_wire/2`: событие и словарь ссылок → `%{title, details}`
для JSON. Презентер события вставляет их рядом со своими машинными полями. Спека — `../spec.md`, «Wire», user
stories 47–51; ADR-0063, ADR-0064.

- [x] Опции: обязательные `codec:` и `user_ref:` с `dump:` — захват функции «дамп id, имя → map» арности 2;
      иное — `CompileError`.
- [x] `to_wire/2`: вид — строкой; число — строкой с десятичной точкой (integer — `Integer.to_string`, decimal —
      нормальная запись); текст, дата и дата-время — дампом `codec:`; ссылка на запись — `%{entity, id, name}`,
      вид записи — camelCase атома; ссылка на учётную запись — результат `dump:` от дампа id и имени; группа и
      список — рекурсивно; изменение — `%{label, kind: "change", old, new}`; у элемента списка и стороны изменения
      нет `label`.
- [x] Id, которого нет в словаре ссылок, — исключение: словарь собирают с той же страницы.
- [x] Порождённая функция следует правилам генерируемых функций (`20-agreements.md`, ADR-0014).
- [x] Эталонная сверка: на обезличенных фикстурах, повторяющих сценарии потребителя A, JSON совпадает с его формой
      `title` / `details` — виды, порядок, «Да» / «Нет», ссылки, числа.
- [x] Фикстура-потребитель (без `open_api_spex`) объявляет модуль с `use Core.Web.Labels`; сборка без предупреждений,
      `make consumer-check` зелёный.
- [x] Свод: `docs/rules/app/15-web-api.md` — сведения уходят на wire через модуль с `use Core.Web.Labels`;
      подмена строк-id в машинной нагрузке — дело приложения.
- [x] `CHANGELOG.md` — дополняется пункт подсистемы подписей; правка `app/**` — тем же коммитом.
- [x] `make` зелёный.
