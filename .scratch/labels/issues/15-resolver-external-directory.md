# 15: резолвер и записи внешнего справочника; скаляры свободной map'ы

**Status:** resolved

**Blocked by:** —

**What to build:** две нормы без правки кода.

1. Норма «id незаведённой записи — отказ» (`Core.Labels.Resolver`, `docs/rules/11-domain.md`, «Словарь
   ссылок») не знает внешних справочников. У потребителя A резолверы четырёх справочников внешней системы
   отдают `nil` на запись, которая ещё не загружена: ссылка законна, запись просто не пришла. Оговорка
   ограничена справочниками внешней системы: для собственной записи контекста незаведённая запись — по-прежнему
   отказ. Цена записывается явно: мусорный id внешнего справочника не ловится и выходит как «имени нет».
2. Значение свободной map'ы — Prim, строка, число, `boolean` или `nil` (moduledoc `Core.Labels.Details`);
   список или map'а в значении — `FunctionClauseError` на странице событий. Сборка и ратчет тип значения не
   видят, поэтому норма: у map'ы с вложенными значениями решение поля — `:hidden`.
