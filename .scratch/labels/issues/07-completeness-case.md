# 07: Ратчет полноты подписей

**Status:** ready-for-agent

**Blocked by:** 02, 04, 05.

**What to build:** автор приложения подключает ратчет полноты одним тест-модулем
(`use Core.Labels.CompletenessCase, app: :my_app`). Ратчет сам находит все кодеки событий и семейства среди модулей
приложения и требует название у каждого события, решение у каждого struct'а, достижимого из нагрузки, подписи у
каждого Enum и вид у каждого типа id. Спека — `../spec.md`, «Модули домена», user stories 55–59; ADR-0063.

- [ ] Опции: обязательная `app:`, необязательная `async:`; иное — `CompileError` через
      `Core.Helper.Opts.validate!`.
- [ ] Модули приложения — `:application.get_key/2`; кодеки — модули с интроспекцией кодека событий; семейства —
      плагины с интроспекцией семейства.
- [ ] Логика — публичные функции `check_*` над набором модулей (`:ok | {:error, пробелы}`), тест —
      `assert :ok = …`; провал перечисляет все пробелы с модулем и полем.
- [ ] Спека `fields:` каждого варианта семейства сверяется со спекой плагина семейства (без поля `variant_by:`).
- [ ] Пустой обход — провал; числовых нижних границ нет.
- [ ] Тесты `check_*` на полном и сломанном наборе: событие без названия, поле без решения, Enum без подписей,
      id без вида, вариант с расходящейся спекой, пустой обход; `use` — только опции. Образец — тест
      `Core.Es.EventCompatCase`.
- [ ] Свод: `docs/rules/app/19-testing.md` — приложение, отдающее сведения событий, MUST подключить ратчет.
- [ ] `CHANGELOG.md` — дополняется пункт подсистемы подписей; правка `app/**` — тем же коммитом.
- [ ] `make` зелёный.
