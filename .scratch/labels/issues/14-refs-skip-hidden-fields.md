# 14: словарь ссылок не обходит скрытые поля

**Status:** resolved

**Blocked by:** —

**What to build:** `Core.Labels.Refs.collect/2` спускается во все поля struct'а через `Map.from_struct/1`,
включая `:hidden`: резолвер зовётся на id, которые в сведения не выходят, и его отказ роняет страницу. Обход
`Refs` должен видеть то же, что `Details`. Общий обходчик не выносится — расхождение ловит тест-инвариант.

- [x] Struct с `__label_fields__/0` — спуск только по видимым полям (`Core.Labels.Fields.specs/1`): у варианта
      семейства — по его полям, у struct'а изменения — `old_value` / `new_value`. Struct без объявления полей —
      как сейчас. Автор события, map'ы, списки, Prim-композит — как сейчас.
- [x] Тест: id только в `:hidden`-поле резолвер не получает.
- [x] Тест-инвариант: каждый id с резолвером из `Details.build/1` есть в словаре `Refs.get/2` (на фикстурах
      со struct'ами, семейством, изменением, свободной map'ой).
- [x] Moduledoc `Refs` и `docs/rules/11-domain.md`, «Словарь ссылок»: «скрытые поля не обходятся».
- [x] `CHANGELOG.md` — дополняется пункт «Подписи событий» в «Новое».
- [x] `make` зелёный.
