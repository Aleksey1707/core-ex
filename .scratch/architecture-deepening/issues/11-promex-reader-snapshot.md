# 11: PromEx — один снимок и deprecated-переход

**What to build:** PromEx для общих gauge'ей читателей читает только `snapshot/1` и не разбирает
четыре формы значения. Kafka-ветка аренды и лагов остаётся отдельной и читает `info/1` своей формы.
`metrics/1` и `info/1` помечаются deprecated, но не удаляются.

**Blocked by:** 10.

**Status:** resolved

- [x] PromEx для общих gauge'ей читает только `snapshot/1`; четыре формы значения и попытка `metrics/1` → `info/1` удалены.
- [x] Kafka-ветка аренды и лагов остаётся отдельной; имена метрик, метки и агрегация по нодам прежние.
- [x] `metrics/1` и `info/1` помечены deprecated для метрик; удаление не делается.
- [x] Тесты PromEx с фейковым читателем зелёные; новый адаптер без `snapshot/1` не считается наблюдаемым и это видно по тесту.
- [x] CHANGELOG: «Новое» (снимок) и deprecated-переход; `make` и `make compile-no-optional` зелёные.
