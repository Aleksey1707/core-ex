# 03: Контракт источника строк вместо тестовой модели снапшота

**What to build:** тестовая модель выбора снапшота удаляется; SQL-адаптер и тестовый источник
строк проверяются одним контрактом на границах снапшота. Тестовый адаптер повторяет два сравнения
SQL явно и опирается на инвариант «одна строка снапшота на поток».

**Blocked by:** 02.

**Status:** ready-for-agent
