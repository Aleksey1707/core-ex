# 04: Заявка на готовность в `get/2` читателей

**What to build:** stream- и Kafka-читатели ждут сообщение по заявке `notify_when_ready/2`, а не
опрашивают вхолостую. DLQ-читатель продолжает опрос: его пустой `get` идёт в базу. Исходы и
интерфейс `get/2` не меняются.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] `get/2` stream-читателя передаёт в общий цикл ожидания заявку на готовность на процесс вызывающего.
- [x] `get/2` Kafka-читателя делает то же.
- [x] DLQ-читатель передаёт `nil` и сохраняет опрос с интервалом.
- [x] Ложная заявка (`:empty` после `{:mq_ready, ref}`) продолжает ожидание; отказ заявки переходит на опрос с интервалом; по дедлайну — `:empty`.
- [x] Контракт читателей и юнит общего цикла ожидания зелёные; живые брокеры — под тегами `:rabbit_stream` / `:kafka`.
- [x] `make` зелёный; CHANGELOG не пополняется.
