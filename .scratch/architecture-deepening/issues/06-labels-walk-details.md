# 06: `Labels.Walk` — общий обход и сведения

**What to build:** появляется внутренний модуль обхода объявленной видимой формы с двумя входами:
значения и объявления. Сведения переходят на обход значений; правила видимости (`hidden`, `text:`,
`change:`, `set`/`map`/`union`, спуск в struct) переезжают в один модуль. Выход сведений и wire не
меняются.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] `Details` использует обход значений; свой разбор видимости удалён или сведён к вызову `Walk`.
- [ ] Тесты сведений зелёные; wire событий с подписями не изменился.
