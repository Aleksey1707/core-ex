# 05: Страница событий → wire одним шагом

**What to build:** генерируемая `use Core.Web.Event` функция `to_wire_page/2` собирает словарь
ссылок со страницы, применяет `to_wire/2` к элементам и сохраняет `total`. Ошибка композиции
(словарь не с той страницы) перестаёт всплывать в `Details.name!/3` на последнем шаге.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] `use Core.Web.Event` порождает `to_wire_page/2`: страница (`%Core.Pagination.Result{}`) и контекст → `Core.Result` со страницей wire-элементов.
- [ ] Функция собирает словарь ссылок один раз со всей страницы, затем применяет свою `to_wire/2` к элементам; `total` и порядок сохраняются.
- [ ] Работают оба профиля: без подписей и с `labels: true`, включая требование `user_ref:`.
- [ ] Отказ резолвера возвращается итогом функции, а не частичным словарём.
- [ ] Тесты на `web_event_fixture`: оба профиля, пустая страница, сохранение `total`, отказ резолвера, отсутствующий id.
