# 01: Фикстуры проекций — тем же шагом, что поток

**What to build:** тест-модуль проекции грузит golden-фикстуру тем же шагом, что путь чтения хранилища
событий: конверт расшифровывается, затем событие грузится кодеком семейства. Рабочая фикстура события
с субъектом данных проходит, уничтоженный ключ даёт уничтоженное значение. Проверка тега, исходы ошибок
и сообщения об отсутствующих фикстурах не меняются.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Фикстура с ПДн-значением загружается через общий шаг хранилища событий: расшифровка конверта и загрузка кодеком семейства; второй копии шага загрузки в тестовом helper'е нет.
- [x] В набор рабочих фикстур событий добавлена фикстура события с субъектом данных (не в набор «сломанных»), и проекция по ней даёт ожидаемую read-модель.
- [x] Фикстура с уничтоженным ключом субъекта даёт уничтоженное ПДн-значение в read-модели.
- [x] Проверка тега конверта выполняется до загрузки; отсутствующая фикстура, сломанный JSON, неверный тег и отказ загрузки дают прежние исходы и тексты.
- [x] Тест-модуль не получил новых обязательных опций и не требует настройки хранилища ключей сверх обычной тестовой конфигурации.
- [x] Существующие тесты проекций и совместимости событий зелёные без правок; `make` зелёный.
