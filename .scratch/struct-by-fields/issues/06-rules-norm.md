# 06: Норма в своде

**What to build:** автор приложения находит в своде, где применять структуру по полям и что проверяют роли, а в
CHANGELOG — как перевести ручной struct.

**Blocked by:** 02, 03, 04, 05

**Status:** ready-for-agent

- [ ] `docs/rules/11-domain.md`: норма MAY для команды, состояния агрегата, вложенной сущности и варианта
      семейства; `optional:` против обязательного ключа; проверки ролей (агрегат, плагин, подписи); ручной
      `defstruct` остаётся допустимым. Ссылка на ADR-0090.
- [ ] `docs/rules/app/**` не меняется.
- [ ] CHANGELOG: итоговый пункт «Новое» с «было → стало» для команды и вложенной сущности с подписями.
- [ ] `make rules-check` и `make` зелёные.
