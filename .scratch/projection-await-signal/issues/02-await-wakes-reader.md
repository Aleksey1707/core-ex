# 02: Ожидание будит читателя проекции

**What to build:** автор usecase ждёт проекцию, а пачка при `wake` после записи не увидела событие — старая пишущая
транзакция кластера держит видимость (ADR-0008) — и читатель ушёл в простой до `poll_interval_ms`. Теперь каждый шаг
`Core.Es.Projection.await/4` будит локального читателя своей проекции, и событие подхватывается за шаг после commit
старой транзакции, а не за секунду.

**Blocked by:** [01: Шаг ожидания — опции дерева](01-await-step-options.md)

**Status:** resolved

**Spec:** [Сигнал чекпоинта: ожидание проекции без задержки опроса](../spec.md) — «Сигналы внутри ноды», «Ожидание»,
«Читатель»

- [x] Ключи `Core.Es.Projection.Registry` — кортеж с видом сигнала: сигнал записи (`wake`) по типу агрегата переходит
      на такой ключ, рядом — пробуждение читателя по имени проекции. Строка типа агрегата и имя проекции не совпадают
      как ключи. Registry не запущен — отправка `:ok`.
- [x] Читатель в `init/1` регистрируется ещё и под ключом пробуждения по имени своей проекции; пробуждение — то же
      сообщение `wake` с прежней обработкой (цикл сразу при `:idle` / `:locked` / до первого цикла, пропуск при
      `:retry` / `:outdated`, счётчик простоя не сбрасывается).
- [x] Режим `:poll`: на каждом шаге ожидающий перечитывает чекпоинт и будит локального читателя своей проекции; первое
      пробуждение — на первом шаге. Нода без Registry (дерево `:ignore`) ждёт одними шагами.
- [x] Сигнал записи `append` и цикл читателя для записей без ожидания не меняются.
- [x] Тест в sandbox (`Core.Es.Projection.AwaitTest`): событие вставлено мимо `append` (без `wake`), интервалы
      читателя 60 000 мс, шаг ожидания короткий → `:ok`.
- [x] Отдельный модуль тестов с настоящими коммитами: `async: false`, процессам дерева — соединения вне sandbox
      (глобальный режим — `:manual`), очистка `es_events`, `es_checkpoints` и read-модели фикстуры в `on_exit`
      (образец — `Core.Es.StoreRaceTest`). Сценарий: старая пишущая транзакция другого соединения держит видимость,
      событие закоммичено, пачка отдала `:idle`; после commit старой транзакции ожидание с коротким шагом при
      интервалах читателя 60 000 мс → `:ok`.
- [x] Регресс: тесты цикла читателя и `wake` в `Core.Es.Projection.SupervisorTest` проходят.
- [x] moduledoc `Core.Es.Projection.Registry` (виды сигналов, ключи), `Core.Es.Projection.Reader` (пробуждение от
      ожидающего), `Core.Es.Projection` («Ожидание» — шаг будит читателя).
- [x] `CHANGELOG.md`, «Не выпущено» / «Новое»: пункт «Read-after-write» дополнен.
- [x] `make` зелёный.
