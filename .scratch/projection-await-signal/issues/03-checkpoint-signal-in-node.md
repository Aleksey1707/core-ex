# 03: Сигнал чекпоинта внутри ноды

**What to build:** на ноде, где прошла пачка, `Core.Es.Projection.await/4` отвечает сразу после её commit, а не на
следующем шаге опроса. Читатель после пачки рассылает сигнал чекпоинта своей проекции, ожидающий подписан на него на
время ожидания. Mailbox вызывающего — GenServer, LiveView — после ожидания остаётся чистым. На одной ноде этого
достаточно для полного быстрого пути.

**Blocked by:** [02: Ожидание будит читателя проекции](02-await-wakes-reader.md)

**Status:** ready-for-agent

**Spec:** [Сигнал чекпоинта: ожидание проекции без задержки опроса](../spec.md) — «Сигналы внутри ноды», «Ожидание»,
«Читатель»

- [ ] Сигнал чекпоинта — ключ Registry по имени проекции; читатель после пачки с исходом `:processed`, включая старт
      пересборки, рассылает его после commit.
- [ ] Режим `:poll`: подписка через alias процесса (`Process.alias/1`) значением записи Registry — до чтения цели и
      чекпоинта; рассылка шлёт на alias. По сигналу своей проекции — перечитать чекпоинт тем же разбором исходов.
- [ ] Шаги идут по расписанию от начала ожидания и сигналами не сдвигаются; `timeout` ограничивает всё ожидание.
- [ ] После ожидания при любом исходе — снятие регистрации, `Process.unalias/1`, вычерпывание доставленных сигналов;
      сигнал чужой проекции ожидание не будит.
- [ ] Registry не запущен — регистрация пропускается, ожидание идёт шагами.
- [ ] Тесты в sandbox (`Core.Es.Projection.AwaitTest`), шаги ожидания 60 000 мс при таймауте в секунды: живое дерево,
      запись через репозиторий → `:ok`; пачка, начавшая пересборку, → `:projection_rebuilding`; после `:ok`, таймаута
      и пересборки в mailbox теста нет сигналов.
- [ ] Регресс: тесты `await: :poll`, `:inline`, пересборки, ошибок программиста, span и telemetry проходят.
- [ ] `17-otp-concurrency.md`, «Имена процессов»: исключение для получателей, которые регистрируются в Registry сами,
      распространяется на ожидающего, которого порождает не дерево; подписка — через alias, чтобы поздний сигнал не
      попал в mailbox вызывающего. `make rules-check`.
- [ ] moduledoc `Core.Es.Projection` («Ожидание» — сигнал чекпоинта), `Core.Es.Projection.Reader` (сигнал после
      пачки), `Core.Es.Projection.Registry`.
- [ ] `CHANGELOG.md`, «Не выпущено» / «Новое»: пункт «Read-after-write» дополнен.
- [ ] `make` зелёный.
