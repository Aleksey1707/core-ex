# 06: Повтор ложного отказа `append` при явной версии

**Status:** needs-triage

**What to build:** повтор после `:version_mismatch` различает источник: отказ стража `append` (конкурент по
тому же потоку без конфликта версии) повторяется при любой версии, отказ `get` / `refresh` по явной
`%Version{}` — нет. Логика доступна приложению публично (сейчас она приватна в
`Core.Es.Aggregate.Process.Execution`), чтобы обёртки повтора в приложениях не повторяли её копией.

**Why:** сейчас повтор только при `:current`; корректный `If-Match` может получить 412 из-за конкурента.
Снаружи отказ `get` и `append` не различить: в detail оба `expected` — целые. Норма —
`app/13-repos.md`, «Повтор при `:current`».
