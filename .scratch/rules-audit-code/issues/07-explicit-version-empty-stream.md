# 07: Явная версия на пустом потоке

**Status:** needs-info

**What to build:** решение: `get(id, %Version{}, context)` на пустом потоке — `:version_mismatch`
(`actual: nil`, сейчас, 412) или незаведённое состояние `version: nil`, а сверку делает `decide` / `append`
(404 от домена). Затем — код и норма в `13-repos.md`, «Write event-sourced агрегата».

**Why:** `13-repos.md` говорит «существование агрегата решает домен», но репозиторий отказывает раньше;
приложение сворачивает этот отказ обратно в пустое состояние своим хелпером в девяти usecases.
