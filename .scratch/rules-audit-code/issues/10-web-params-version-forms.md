## Agent Brief

**Category:** enhancement
**Summary:** `Core.Web.Params` — `explicit_version/2`, `expected_version/2`, `optional_version/2` вместо
`version/2` и норма формы `If-Match` для команды и чтения

**Current behavior:**
`Core.Web.Params.version/2` — обязательный заголовок и `Version.parse/1`: `"*"` → `:current`, нет заголовка —
`:missing_param` (400). Строгой и необязательной форм нет. Норма `app/15-web-api.md`, «Controller», форму не
выбирает, а `app/13-repos.md`, «Повтор при `:current`», уже допускает `:current` на команде с повтором.

Потребители разбирают по-своему:

- qc — `QCWeb.Helper.IfMatch`: `strict` (25 вызовов, команды), `optional` (9, все в `show` → `get(id, version)`,
  412 при расхождении), `parse` = `Params.version` (2, `grant` / `revoke` ролей — `*` на команде). Заголовок
  проверяет `CastAndValidate` по схеме до контроллера;
- counters — `get_req_header(conn, "if-match")`: нет заголовка или `*` на изменяющем запросе → `:current`;
- messages — inline `Params.get(:"If-Match")` + `Version.new` (1 контроллер) / `Version.parse` (2), плюс
  `:version` элемента тела пачки.

`Version.new("*")` отвечает `%Error{ns: :prim, code: :invalid_integer, message: "Версия: невалидное значение"}` —
текст неверен для корректного по RFC `*`.

**Desired behavior:**

| Функция | Нет заголовка / `nil` | `*` | Результат |
|---|---|---|---|
| `explicit_version/2` | `:missing_param` (400) | `%Error{kind: :domain, ns: :web, code: :current_not_allowed, detail: key}`, текст «`*` недопустим: нужна явная версия» (400) | `{:ok, Version.t()}` |
| `expected_version/2` | `:missing_param` (400) | `{:ok, :current}` | `{:ok, Version.expected()}` |
| `optional_version/2` | `{:ok, :current}` | `{:ok, :current}` | `{:ok, Version.expected()}` |

- у всех трёх `key \\ :"If-Match"`: `key` — имя параметра схемы запроса, а не заголовок `conn` (как в `@doc`
  нынешней `version/2`);
- `""` и мусор — ошибка разбора `Version` (400) во всех формах;
- `explicit_version/2` сужает результат паттерном в теле (`{:ok, %Version{} = version} -> {:ok, version}`), а не
  `Result.and_then(&Version.new/1)`: иначе вывод типов даёт потребителю `dynamic()` (ADR-0014);
- `version/2` удаляется: поломка видна потребителю при компиляции, прямой вызов сейчас один (делегат хелпера qc);
- `Core.Web.ErrorMapper` не меняется: `:current_not_allowed` — 400 по строке `kind: :domain`; 428 не вводится.

Норма `app/15-web-api.md`, «Controller», — пункт «Optimistic lock» заменяется:

- команда — `explicit_version/2`;
- `*` на команде MAY — `expected_version/2`, если исход команды не зависит от состояния, которое видел клиент
  (выдача роли, увеличение счётчика);
- команда без `If-Match` MUST NOT: забытый заголовок молча затирает конкурентные изменения, `*` — видимое намерение;
- чтение по версии — `optional_version/2`;
- параметр `If-Match` в `operation/2` SHOULD описываться той же формой, что и разбор (`required` и тип: целое или
  «целое | `*`»);
- фраза про `If-Match` над незаведённым event-sourced агрегатом сохраняется.
