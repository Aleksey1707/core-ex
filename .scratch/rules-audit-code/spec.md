# Аудит свода по использованию в приложении: правки кода

Аудит свода `docs/rules/**` против приложения-потребителя (17.09.2026) нашёл дефекты, которые
чинятся не текстом свода, а API библиотеки. Свод и линтеры поправлены в той же задаче; здесь —
отложенные правки кода, по тикету на каждую. Все тикеты сырые: перед работой — триаж.

Общий признак: приложение пишет у себя то, что нужно любому потребителю, либо обходит контракт
библиотеки, и каждый потребитель повторяет одну и ту же обвязку.
