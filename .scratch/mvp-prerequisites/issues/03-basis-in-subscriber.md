# 03: Основание у подписчика

**What to build:** обработчик `on_message` получает в контексте основание — операцию события, на которое он
реагирует. Обработчик для этого ничего не делает. Если реакция записывает события, они несут это основание.
Сообщение без заголовка `operation_id` (внешний источник, старая запись outbox) обрабатывается без основания.

Спека — «Конверт операции», основание у подписчика; ADR-0081.

**Blocked by:** 01, 02
