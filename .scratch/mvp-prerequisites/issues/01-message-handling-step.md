# 01: Шаг обработки сообщения (префакторинг)

**What to build:** обработка одного сообщения подписчиком вызывается как функция, а не только изнутри цикла
GenServer. Шаг делает следующее:

1. `filter`;
2. span `process` с родителем из заголовков;
3. `from_message`;
4. контекст от `context_factory`;
5. `on_message`;
6. перехват исключения в `{:error, %Error{}}`.

Исход шага — обработано / отфильтровано / повтор с ошибкой / отказ без повторов. `MqSubscriberReliable` зовёт этот
шаг и оставляет за собой чтение, `commit`, счёт попыток, backoff, DLQ-writer и telemetry цикла. Поведение подписчика
не меняется. Шаг — общий вход для основания (03) и дублёра доставки (04).

Спека — «Дублёр доставки», шаг обработки; ADR-0082.
