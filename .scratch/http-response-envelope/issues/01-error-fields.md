# 01: Ошибки по полям в `data.fields`

**What to build:** ошибка валидации входа отдаётся клиенту по путям полей —
`data.fields: {поле: [тексты]}`, вложенно, индекс элемента списка — строковый ключ, ошибка
уровня объекта — под `"_schema"` (форма проекта-образца, `research.md`, «Ошибки валидации»).
Для этого `%Error{}` должен нести путь поля: новое поле, `detail` или ключи элементов `errors` —
решить на грилинге, это правка модели ошибки (`docs/rules/12-errors.md`).

**Blocked by:** обёртка ответа (ADR-0062)

**Status:** needs-triage

**Spec:** ADR-0062, «Рассмотренные варианты» — отложенные ошибки по полям
