## Comments

Разметку потребовал один файл — `es_aggregate_repo_contract.ex`: три возврата private → public на уровне модуля
(`refresh_tests` → `open`, `at` → `execute!`, `drain_queries` → `dump`). Блоков вышло шесть, а не четыре: границы
«таблицы» и «счёт запросов» режут переход public → public, иначе имя блока называло бы «остальное». Кросс-блочных
приватных в файле нет (`by` / `at` зовутся только из «команд», `counted?` / `drain_queries` — только из «счёта
запросов»), поэтому хвостовой `общее` не понадобился нигде в `test/support/**`.

Остальные файлы `support` размечены верно и до правки: возврат есть только здесь, девять переходов public → private
несут `# ---`, модули с одним блоком `# =====` не несут. Текстовый «возврат» в `mq_fake.ex` (78 → 106) — граница
`Writer` / `QueueReader`, то есть двух самостоятельных единиц.

`# ===== aggregate =====` в `account.ex` снят — это правка сверх «сверить форму», и вот почему. Под маркером нет ни
одного определения из списков «публичное / приватное»: только вложенные `defmodule`, `@typedoc` / `@type` и
атрибут, а вложенный `defmodule` — самостоятельная единица со своим счётом блоков. В `lib/**` такая секция живёт до
первого маркера как преамбула (`es/store.ex`: `@type` на 97–115, `# ===== запись =====` на 116; `checkpoint.ex`:
`@typedoc` / `@type` на 34–43, `# ===== блокировка =====` на 44), а блок без публичных определений там встречается
только хвостовым `общее` — ровно то, что забракует проверка (6) тикета 04. Имена `decide` и `evolve` — колбэки
`Core.Es.Aggregate`, термины кода, остаются. Формулировка ADR-0012 «разметка `codec.ex` и `account.ex` остаётся
законной без правок» этим устарела и поправлена в том же коммите.

Форма маркеров в `test/**` вне `support` проверена скриптом (ровно `# ---` / `# ===== <имя> =====`, отступ как у
следующего определения, пустые строки сверху и снизу, ни один не стоит между `@spec` / `@doc` и `def`) — расхождений
нет, файлы не тронуты.
