# 01: Свод и ADR: разделители как два уровня

**What to build:** раздел «Разделители внутри модуля» в `docs/rules/20-agreements.md` переписан под модель двух
уровней — `# ---` как падение уровня абстракции внутри блока, `# ===== <имя> =====` как граница блока и возврат
уровня наверх. Обоснование и разбор отвергнутых вариантов уходят в `docs/adr/0012-module-separators.md`.

**Status:** done

**Spec:** [Разделители внутри модуля](../spec.md)

- [x] Структура: один H2 «Разделители внутри модуля», внутри три H3 — «Переход к приватным (`# ---`)»,
      «Блоки (`# ===== … =====`)», «Общие приватные». H4 MUST NOT (`00-index.md`).
- [x] Нормы: переход public → private — `# ---` MUST; возврат private → public открывает блок и MUST быть
      предварён `# ===== <имя> =====`; модуль с одним блоком `# =====` MUST NOT; модуль с ≥2 блоками размечает
      каждый, включая первый.
- [x] Хвостовой блок `# ===== общее =====` — дом приватного, вызываемого более чем из одного блока: только
      последний в модуле, `# ---` внутри MUST NOT (отделять нечего).
- [x] Переходом считается любая пара из списков: публичное — `def` / `defmacro` / `defguard` / `defdelegate`,
      приватное — `defp` / `defmacrop` / `defguardp`.
- [x] Форма: ровно `# ---` и `# ===== <имя> =====` (пять `=` с каждой стороны), отступ как у определений модуля,
      пустая строка сверху и снизу, маркер перед `@doc` / `@spec` первой функции блока, а не между спекой и
      определением.
- [x] Имена блоков — русские; английское имя MAY, только если это термин кода. Примеры в тексте заменить на
      реальные: `билдер`, `опции профиля`, `dump`, `load`, `coerce` (`lib/core/codec.ex`), `aggregate`, `decide`,
      `evolve` (`test/support/es_fixture/account.ex`). Пример `private` из списка имён убрать — его случай теперь
      закрывает `общее`.
- [x] Сохранить действующие оговорки: внутри `quote` MUST NOT; вложенный `defmodule` размечается самостоятельно;
      модуль без публичных функций разделителя не требует; тест-модули — MAY.
- [x] Пример «плохо / хорошо» на возврате private → public — сейчас в разделе его нет, а именно этот случай и
      расходился с кодом.
- [x] `docs/adr/0012-module-separators.md` по шаблону `docs/adr/`: контекст с цифрами (95 из 140, 30 файлов с
      возвратом, 3 файла с блоками, 37 кросс-блочных приватных); рассмотренные варианты — один маркер `# ---`
      против двух уровней против отказа от `# =====`; дом общего приватного — хвост против первого вызывающего
      против запрета; скрипт против Credo-чека; последствия — 28 файлов приведения, ~37 переносов, новый шаг
      `make`.
- [x] Ссылка `ADR-0012` из раздела свода (`00-index.md`: правило без обоснования уносит ссылку на ADR).
- [x] Строку `Проверяется: make layout-check` здесь **не** добавлять — её ставит тикет 04 вместе с целью
      (`00-index.md`: строка ставится только там, где проверка существует).
