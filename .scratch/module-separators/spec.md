# Разделители внутри модуля: два уровня и линтер

Type: spec
Status: ready-for-agent

## Problem Statement

`docs/rules/20-agreements.md`, раздел «Разделители внутри модуля», описывает два маркера — `# ---` и
`# ===== <блок> =====` — как взаимоисключающие режимы: «Модуль, разбитый на смысловые блоки, размечается
комментарием `# ===== <блок> =====`… Если такого деления нет, MUST как минимум отделять публичные функции от
приватных строкой `# ---`». Код живёт иначе, и правило расходится и с ним, и с самим собой.

- **Режимы не взаимоисключающи.** `lib/core/codec.ex` и `lib/core/codec/redump.ex` используют оба маркера сразу и
  вложенно: `# ===== блок =====` открывает блок, внутри блока `# ---` отделяет приватные.
- **Возврат наверх невидим.** Переход public → private размечен в 95 файлах из 140 (файлов с `defp` без `# ---` —
  ноль). Обратный переход — возврат к публичной функции после приватных — встречается в 30 файлах и размечен
  только в двух. В остальных 28 читатель не видит, что уровень абстракции вернулся наверх.
- **Правило почти мертво.** `# ===== =====` стоит в 3 файлах из 140, включая `test/support/es_fixture/account.ex`.
  Порог «модуль, разбитый на смысловые блоки» цикличен: модуль разбит, потому что размечен.
- **Имена блоков разноязыки.** Примеры в своде английские (`aggregate`, `domain ops`, `factory`, `private`), в коде
  русские (`билдер`, `опции профиля`, `спека`) вперемешку с английскими (`dump`, `load`, `coerce`).
- **Пример `private` противоречит правилу понижения.** Блок с таким именем — хвост из всех приватных, а соседняя
  норма требует держать приватный хелпер сразу под его публичным вызывающим.
- **Проверки нет.** Правило на 181 месте держится на дисциплине, тогда как `00-index.md` требует от правила пример
  «плохо / хорошо» либо строку `Проверяется: …`.

## Solution

Маркеры — два уровня одной модели, а не два режима.

- `# ---` — **падение уровня абстракции** внутри блока: ниже идут детали реализации того, что выше.
- `# ===== <имя> =====` — **граница смыслового блока**, то есть возврат уровня наверх.

Возврат private → public перестаёт быть немым: он и есть начало нового блока.

### Нормы

| Случай | Норма |
|---|---|
| переход public → private | `# ---` MUST |
| возврат private → public | открывает новый блок: `# ===== <имя> =====` MUST |
| модуль с одним блоком | `# ===== =====` MUST NOT — хватает `# ---` |
| модуль с ≥2 блоками | размечен каждый блок, включая первый |
| приватный, вызываемый более чем из одного блока | хвостовой блок `# ===== общее =====` |
| хвостовой блок | только последний в модуле; `# ---` внутри MUST NOT |
| `test/**` кроме `support` | MAY; проверяется форма, не наличие |
| внутри `quote` | MUST NOT |
| вложенный `defmodule` | самостоятельная единица со своим счётом блоков |

Публичное — `def` / `defmacro` / `defguard` / `defdelegate`; приватное — `defp` / `defmacrop` / `defguardp`.
Переходом считается любая пара из этих списков.

Форма — ровно `# ---` и `# ===== <имя> =====` (пять `=` с каждой стороны), отступ как у определений модуля, пустая
строка сверху и снизу. Маркер ставится перед `@doc` / `@spec` первой функции блока, а не между спекой и
определением.

Имена блоков — русские; английское имя — только если это уже термин кода (`dump`, `load`, `decide`, `evolve`).

### Проверка

`scripts/layout_lint.exs`, цель `make layout-check` после `rules-check`, хук в `.pre-commit-config.yaml` на том же
месте цепочки. Скрипт проверяет `lib/**` и `test/support/**` целиком, в `test/**` — только форму маркеров.

### Почему так

Разбор вариантов — `docs/adr/0012-module-separators.md` (заводится тикетом 01): за отказом от `# =====` стояли
138 файлов из 140, дом общего приватного выбирался из трёх вариантов, скрипт взят вместо Credo-чека, потому что
`# ---` — комментарий, и в AST его нет.

## Объём

28 файлов `lib/**` получают маркеры блоков, и каждому блоку нужно имя; около 37 приватных, вызываемых из
нескольких блоков, уезжают в хвостовой `общее`. Тикет 04 идёт последним, чтобы `make` не краснел по пути.
