# Решения опроса по ослаблению свода

Источник кандидатов — `survey.md`. Нумерация вопросов — сквозная по раундам опроса.

## Раунд 1

| Q | Кандидат | Решение |
|---|---|---|
| Q1 | R1-1 | `DEBT.md` — только отступления от нормы: одна причина и условие снятия. Инвентарь (циклы) — не в `DEBT.md`; пробелы покрытия и отложенная функциональность — трекер задач приложения, `DEBT.md` на него ссылается; неподключённый SDK — одна строка «чем платим» |
| Q2 | R2-1 | Одна норма «до первого релиза» на ярус потребителя: wire событий, expand/contract, версия API, заполнение резервов, история миграций; базы после pull пересоздаются; пооперационного учёта нет; частные исключения ссылаются на общую норму |
| Q3 | R2-3 | Узко: в `evolve/2` bang допустим для любой чистой операции над событием и константами кода; перечень «Safe vs bang» остаётся перечнем, принципом не обобщается |
| Q4 | R2-2 | MAY: неизменяемый естественный ключ — UUID источника, уникальный на все виды, которые из него грузятся → id потока равен ему. В библиотеке — Prim без генерации `new/0` |
| Q5 | R2-4 | MAY: изменяющий прогон выбирает кандидатов через ReadRepo, если в мутацию уходят только id и версия, а мутация каждого — свой load/save |
| Q6 | R2-5 | MAY: read-модель без таблицы, которую не отдаёт граница, возвращает неизменяемое доменное значение и кешируется так же |
| Q7 | № 21, № 24 | Оба — C, долг потребителя: водяной знак у «прочитать всё»; посев ключа-синглтона один раз на прогон |

## Раунд 2

| Q | Кандидат | Решение |
|---|---|---|
| Q8 | R2-1 | Первый релиз — один момент на приложение: первое из «база, которую нельзя пересоздать» и «потребитель любого контракта вне команды». Обязательная строка локального свода в обоих состояниях: «не состоялся» / «<дата>, <версия>». ADR-0035 |
| Q9 | R1-1 | Требование перечня циклов в `DEBT.md` (`app/20`) снимается; норма о гейте на каскад остаётся |
| Q10 | R2-2 | `use Core.Prim.UUID, version: :external`: без `new/0` и `from_key/1`, версия на разборе не проверяется, `check_version:` / `namespace:` / `scope:` запрещены. ADR-0036 |
| Q11 | R2-6 (E1) | C: литеральные имена процессов рядом с топиками у потребителя; свод и библиотека не меняются |
| Q12 | R2-7 (E3) | Отдельный тикет диагностики `is_enum/2` на enum из отдельного файла (`:unavailable`), воспроизведение в `fixtures/consumer`; свод — по итогу |
| Q13 | № 12 | «Форма панелей» в `app/21` — отдельной задачей, не в этой работе |
| Q14 | — | ADR-0035 (Q2 + Q8), ADR-0036 (Q4 + Q10); ADR-0017 не правится |

Термины `CONTEXT.md`: «Первый релиз», «Внешний идентификатор».
