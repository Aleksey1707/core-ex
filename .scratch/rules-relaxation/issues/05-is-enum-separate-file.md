# 05: Диагностика `is_enum/2` на enum из отдельного файла

**What to build:** автор агрегата использует `is_enum/2` в guard на enum, объявленном отдельным
файлом рядом с агрегатом, — либо это работает, либо свод называет допустимый обход и причину. Сейчас
такая сборка падает с `CompileError … :unavailable` (параллельный компилятор считает ожидание
дедлоком), хотя вложенный `defmodule` выше по тексту работает, а цикла enum → агрегат в исходниках
у потребителя A нет. Потребитель обходит это `cast/1` в теле.

## Comments

**Причина.** Дефекта enum-из-отдельного-файла нет: `is_enum/2` в guard собственного агрегата на enum
отдельным файлом собирается — и на фикстуре, и на коде потребителя A (текущем и на ревизии, где
появился обход, с ядром ещё внутри приложения). Падает другое: вызов коротким именем **без `alias`**
(`is_enum(status, Status)` внутри агрегата). Такое имя раскрывается в корневой `Elixir.Status`,
которого нет; `Code.ensure_compiled/1` (мягкое ожидание) ждёт его, а остальные файлы ждут struct
агрегата. Когда ждут все, параллельный компилятор (`Kernel.ParallelCompiler`, разрешение дедлока)
первым отпускает мягкие ожидания без известного определения с `:deadlock` → `{:error, :unavailable}`,
а не `:nofile`. Отсюда `failed to compile Status: :unavailable` — короткое имя в тексте ошибки и
есть след: у потребителя A сообщение совпало дословно на воспроизведении. Соседние модули
(usecases, шаги) зовут `Agg.Status` через алиас агрегата — потому у них «работало»; вложенный
`defmodule` получает автоматический алиас — потому «работал» и он.

**Исход A.** `Core.Guard` при отказе `ensure_compiled` на одно-сегментном имени дописывает к ошибке
причину: «короткое имя без alias раскрывается в корневой модуль; если имелся в виду `<Caller>.Status` —
нужен alias или полное имя» (тест в `test/core/guard_test.exs`). Контракт макроса не менялся —
CHANGELOG не нужен. Фикстура: `Order.Status` отдельным файлом и `Order.status?/2` с
`is_enum(status, Status)` под `make consumer-check` — храповик держит рабочую форму; красная форма
(без `alias`) — ошибка компиляции, `consumer-check` её держать не может, она проверена вручную, а текст
подсказки держит юнит-тест. Сверх исхода A — уточнение `20-agreements.md`, «Паттерн-матчинг и
арность»: enum своего агрегата отдельным файлом MAY в guard, имя MUST через `alias` или полное.

Потребителю A: локальное правило «guard физически неприменим внутри агрегата» и обход `cast/1` в
фабрике уведомления снимаются — достаточно `alias` (или `__MODULE__.Status`).
