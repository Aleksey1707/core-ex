# 02: Норма «до первого релиза»

**What to build:** разработчик ещё не выпущенного приложения меняет wire событий, схему (expand /
contract, история миграций), версию API и резервы ключа на месте, без апкастов, новых версий и
пооперационных строк `DEBT.md`; базы после pull пересоздаются. Состояние «выпущено / нет» агент
читает одной обязательной строкой локального свода. После первого релиза нормы совместимости
действуют полностью, а отсутствие строки не считается «до релиза».

**Blocked by:** None (can start immediately)

**Status:** done

**Spec:** [Ослабление свода по отступлениям потребителя](../spec.md)

**ADR:** [0035 — нормы совместимости действуют с первого релиза](../../../docs/adr/0035-compatibility-after-first-release.md)
