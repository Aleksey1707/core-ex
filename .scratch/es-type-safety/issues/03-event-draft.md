# 03: Черновик события — `Event.Codec.draft/1,2`

**What to build:** автор агрегата строит элемент результата `decide` вызовом `Event.Codec.draft(Event.X, payload)` или
`Event.Codec.draft(Event.Y)`, и сборка сообщает о событии не из кодека агрегата, о нагрузке другого события и о событии
с нагрузкой, построенном без неё. Кодек, где два события делят модуль нагрузки, собирается. `execute`,
`Aggregate.Test.given/3` и тесты, сравнивающие результат `decide` с кортежами, работают как раньше.

**Blocked by:** 01

**Status:** resolved

**Spec:** [Типобезопасность потребителя `Core.Es`](../spec.md) — «Черновик события — `draft` в `Core.Es.Event.Codec`»

- [x] `use Core.Es.Event.Codec` генерирует по `tags:` (без источников `upcasts:`): `draft/2` — clause на каждое событие
      с нагрузкой, пара «модуль события — struct его нагрузки»; `draft/1` — clause на каждое событие без нагрузки.
      Возврат — элемент результата `decide` (`Es.Aggregate.result()`), как сейчас.
- [x] Модуль нагрузки, общий у нескольких событий кодека, ошибкой не является; форма вызова одна для всех событий.
- [x] Циклов компиляции не добавляется: `make xref` без изменений.
- [x] Фикстура: маркеры — событие другого кодека, нагрузка другого агрегата (литерал и через `Payload.new`), нагрузка
      другого события того же кодека, `draft/1` события с нагрузкой, не-struct вместо нагрузки. `decide` корректного
      потребителя переведён на `draft`, включая кодек с общим модулем нагрузки, — ноль предупреждений.
- [x] `decide` агрегата `test/support/es_fixture` переведён на `draft`; тесты кодека проверяют, что `draft` отдаёт
      элемент результата `decide`; тесты агрегата и `given/3` — прежние исходы.
- [x] moduledoc `Core.Es.Event.Codec` (`draft`, занятые имена `draft/1` и `draft/2`) и `Core.Es.Aggregate` (пример и
      описание результата `decide`).
- [x] `11-domain.md`: элемент результата `decide` строится только через `draft`, ссылка на термин «Черновик события»
      (`CONTEXT.md`); примеры `decide` в своде и ярусе `app/` переведены; `app/00-index.md` — строка карты
      «`{Event.X, payload}` → `Event.Codec.draft(Event.X, payload)`».
