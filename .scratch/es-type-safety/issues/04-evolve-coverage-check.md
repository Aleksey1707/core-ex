# 04: Полнота `evolve` при сборке — функции-проверки

**What to build:** автор агрегата получает предупреждение при сборке, указывающее на строку `use` репозитория агрегата,
если у `evolve/2` нет clause для события кодека, если он опечатался в ключе `%{state | …}` или в поле нагрузки, не
сузив её паттерном. Имя функции в сообщении называет нарушенное утверждение (`"evolve/2 принимает <Event>"`). Проверка
полноты `evolve` в `EventCompatCase` больше не нужна и удалена. Тикет заводит механику функций-проверок, которую
переиспользуют проверки проекции и кодека.

**Blocked by:** 01

**Status:** ready-for-agent

**Spec:** [Типобезопасность потребителя `Core.Es`](../spec.md) — «Функции-проверки полноты», «Тестовые модули»

- [ ] `use Core.Es.Aggregate.Repo` генерирует функцию-проверку на каждое событие кодека агрегата: литеральный вызов
      `evolve/2` с `%Agg{}` и событием, суженным только по `payload:` (`%Payload{}` или `nil`).
- [ ] Механика функций-проверок — одна на три проверки: имя-утверждение; укорачивание модуля в имени до последних
      сегментов, если атом приближается к 255 символам; сборка атома при компиляции с комментарием для
      `Credo.Check.Warning.UnsafeToAtom`; `@doc false`; место предупреждения — строка `use`; функция-проверка
      `generated: true` не размечается.
- [ ] Фикстура: маркеры C1, C2a, C4. Корректные: `evolve` с `%Payload{}` в паттерне и без, события без нагрузки, кодек
      только из событий без нагрузки, кодек с `upcasts:` — ноль предупреждений.
- [ ] `Core.Es.EventCompatCase`: тест clause `evolve/2` на каждый тег и тип `unhandled` удалены; опции `aggregate:` и
      `event_codec:`, golden-проверки и апкаст — прежние. Тесты удалённой проверки убраны.
- [ ] Фикстуры core-ex, намеренно лишённые clause `evolve` ради удалённой проверки (`BrokenAccount` и подобные),
      перестроены или удалены; сборка core-ex с `--warnings-as-errors` зелёная.
- [ ] moduledoc `Core.Es.Aggregate.Repo` (проверка и её место), `Core.Es.Aggregate` (полнота `evolve` проверяется при
      сборке через репозиторий; агрегат без репозитория не проверяется), `Core.Es.EventCompatCase`.
- [ ] `11-domain.md`, `19-testing.md` обоих ярусов — где полнота `evolve` приписана `EventCompatCase`; описание скилла
      `testing`.
- [ ] `CHANGELOG.md`, «Не выпущено»: пункт `EventCompatCase` / агрегата дополнен — полнота `evolve` при сборке, тест
      удалён, «было → стало».
