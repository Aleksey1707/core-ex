# 04: Полнота `evolve` при сборке — функции-проверки

**What to build:** автор агрегата получает предупреждение при сборке, указывающее на строку `use` репозитория агрегата,
если у `evolve/2` нет clause для события кодека, если он опечатался в ключе `%{state | …}` или в поле нагрузки, не
сузив её паттерном. Имя функции в сообщении называет нарушенное утверждение (`"evolve/2 принимает <Event>"`). Проверка
полноты `evolve` в `EventCompatCase` больше не нужна и удалена. Тикет заводит механику функций-проверок, которую
переиспользуют проверки проекции и кодека.

**Blocked by:** 01

**Status:** resolved

**Spec:** [Типобезопасность потребителя `Core.Es`](../spec.md) — «Функции-проверки полноты», «Тестовые модули»

- [x] `use Core.Es.Aggregate.Repo` генерирует функцию-проверку на каждое событие кодека агрегата: литеральный вызов
      `evolve/2` с `%Agg{}` и событием, суженным только по `payload:` (`%Payload{}` или `nil`).
- [x] Механика функций-проверок — одна на три проверки: имя-утверждение; укорачивание модуля в имени до последних
      сегментов, если атом приближается к 255 символам; сборка атома при компиляции с комментарием для
      `Credo.Check.Warning.UnsafeToAtom`; `@doc false`; место предупреждения — строка `use`; функция-проверка
      `generated: true` не размечается.
- [x] Фикстура: маркеры C1, C2a, C4. Корректные: `evolve` с `%Payload{}` в паттерне и без, события без нагрузки, кодек
      только из событий без нагрузки, кодек с `upcasts:` — ноль предупреждений.
- [x] `Core.Es.EventCompatCase`: тест clause `evolve/2` на каждый тег и тип `unhandled` удалены; опции `aggregate:` и
      `event_codec:`, golden-проверки и апкаст — прежние. Тесты удалённой проверки убраны.
- [x] Фикстуры core-ex, намеренно лишённые clause `evolve` ради удалённой проверки (`BrokenAccount` и подобные),
      перестроены или удалены; сборка core-ex с `--warnings-as-errors` зелёная.
- [x] moduledoc `Core.Es.Aggregate.Repo` (проверка и её место), `Core.Es.Aggregate` (полнота `evolve` проверяется при
      сборке через репозиторий; агрегат без репозитория не проверяется), `Core.Es.EventCompatCase`.
- [x] `11-domain.md`, `19-testing.md` обоих ярусов — где полнота `evolve` приписана `EventCompatCase`; описание скилла
      `testing`.
- [x] `CHANGELOG.md`, «Не выпущено»: пункт `EventCompatCase` / агрегата дополнен — полнота `evolve` при сборке, тест
      удалён, «было → стало».
- [x] `make` зелёный.

Prior art: `.scratch/es-type-safety/prototype/lib.diff` (`aggregate/repo.ex`, `event/codec.ex` — имена и строка `use`),
раздел P2 в `RESULTS.md` (сообщение, путь к читаемой форме, ложные срабатывания), мини-проверка
`research/03-grilling-checks/q.ex`.

## Comments

- 2026-09-17 — реализация:
  - механика — `Core.Es.Check`: `define/5` (имя-утверждение, `@doc false`, строка `use` на всех узлах AST
    через `Macro.prewalk`, чтобы вызывающему не размечать аргументы и тело самому; `generated: true` не
    ставится) и `event_pattern/1` (`payload: %Payload{}` / `nil`). Проверки 05 и 06 зовут те же функции;
  - предел имени — 223 символа, а не 255: компилятор Erlang строит из имени служебные атомы
    (`-inlined-<имя>/2-`), и 255-символьное имя роняло сборку `SystemLimitError` в `core_to_ssa`. Не
    помещающийся модуль укорачивается до последних сегментов с `…` в начале;
  - `use Core.Es.Aggregate.Repo` грузит кодек через `Es.Store.Opts.event_codec!/2`, как `Repo.Pg` и процесс.
    Прямые рёбра репозитория у фикстуры (`mix xref graph --source`) — агрегат (compile) и семейство событий
    (export): новых compile-рёбер и циклов нет, ADR-0014 не правится;
  - фикстура: `lib/scenarios/evolve.ex` — маркеры C1 (×2, `Frozen` и `Closed`), C2a, C4 и C1l (событие с
    именем модуля длиннее предела: без укорачивания сборка падает). `Consumer.Account.evolve` — clause
    `Renamed` без паттерна `%Payload{}`, `Opened` — с ним. Проверено вручную, что голова `evolve` с условием
    на состояние (`%__MODULE__{status: :open}`) проверкой не ловится — пример «плохо» в `11-domain.md`
    переформулирован. Маркеров 78 (было 73);
  - `EventCompatCase`: `check_evolve/3`, `evolve_test/2`, тип `unhandled` удалены; `load_fixture`,
    `check_type`, `tag` переехали из блока «общее» в «загрузка фикстур» — других вызывающих у них не
    осталось. `BrokenAccount` удалён вместе с тестом: других пользователей у него не было;
  - сверх перечня: `14-events-outbox.md` и строка карты в `app/00-index.md` приписывали полноту `evolve`
    опции `aggregate:`.
- 2026-09-17 — по ревью: кодек — `Es.Store.Opts.event_codec!/2` вместо третьей формы через `Helper.Opts`;
  отрицательные «case не проверяет» в своде и moduledoc переписаны утверждением, где проверка живёт;
  `app/19-testing.md` — ссылка на `deps/core/docs/rules/11-domain.md`; из moduledoc `Core.Es.Check` убрана
