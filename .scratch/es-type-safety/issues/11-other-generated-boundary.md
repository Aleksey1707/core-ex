# 11: Граница остальных генерируемых функций `Core`

**What to build:** автор приложения получает предупреждение при сборке на типовые ошибки вызовов функций, которые
генерируют `Core.View`, `Core.Enum`, `Core.Context.Accessor`, Prim-профиль `Core.Codec`, `Core.Codec.Plugin`,
`Core.Es.Outbox`, `Core.Es.ValueChanged` и `Core.Prim.*` (кроме bang-конструкторов тикета 02): чужой struct, опечатка
в поле результата, невозможная clause. Поведение при исполнении прежнее.

**Blocked by:** 01

**Status:** ready-for-agent

**Spec:** [Типобезопасность потребителя `Core.Es`](../spec.md) — «Остальные генерируемые функции `Core`», «Граница типов
генерируемых функций»

- [ ] Фикстура получает по модулю каждого вида и сценарии типовых ошибок для каждой публичной генерируемой функции;
      сначала фиксируется, какие ловятся сейчас (маркеры).
- [ ] Молчащие сценарии становятся видимыми: закрытые головы вместо `is_struct/2`, сужение результатов в
      `generated: true`.
- [ ] Правка без сценария, который она делает видимым, не вносится. Сценарий, который видимым не сделать (например,
      элементы списка в `Outbox.from_events`), записан в комментарии тикета с причиной — он уходит в таблицу пределов
      компилятора (тикет 13).
- [ ] Корректные вызовы в фикстуре — ноль предупреждений.
- [ ] ExUnit затронутых модулей — прежние исходы.
- [ ] moduledoc и свод (`11-domain.md`, `14-events-outbox.md`) — если меняются типы результатов или занятые имена.
- [ ] `CHANGELOG.md` — по правилам CHANGELOG, если изменение видно потребителю.
- [ ] `make` зелёный.

Тикет крупный по охвату: если он не помещается в одно окно, его делят по модулям на месте, сохраняя общий критерий
приёмки.
